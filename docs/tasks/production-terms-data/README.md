# Production Terms — working data

Extracted from `books/tech/production-terms/production-terms.html`, which holds
the original 607-term artifact in a `const TERMS` array.

| File | Contents |
|---|---|
| `0N-<booklet>.json` | the terms allocated to that booklet, after the cut |
| `kept.json` | all 403 surviving terms |
| `cut.json` | the 171 dropped terms, each with the rule it failed |

Each term object: `term`, `sub`, `cat`, `means`, `example`, `diagram` — plus
`how`, `more`, `diagram2` on the 141 AI-cluster terms.

These were originally generated into a session scratchpad, which does not
survive a new session. They live here so the work can be picked up at any time.
