# AI Engineering: From Scratch

## Reinforcement Learning from Human Feedback (RLHF)

Pre-training on the internet teaches a model how to speak, but it doesn't teach it how to be a helpful assistant. It might respond to a question by asking another question (because forum threads look like that). 

**RLHF** (introduced by OpenAI for ChatGPT) bridges this gap.

### The 3-Step Process

1. **Supervised Fine-Tuning (SFT):** Human labelers write high-quality, ideal responses to thousands of prompts. The model is fine-tuned to mimic them.
2. **Train a Reward Model:** The SFT model generates 4 different answers to a single prompt. A human ranks them from best to worst. A new neural network (the Reward Model) is trained to look at an answer and output a scalar score predicting the human's preference.
3. **PPO Optimization:** The original model generates answers. The Reward Model scores them. The original model uses PPO to update its weights to maximize that score. 

RLHF is why models are polite, refuse illegal requests, and format lists nicely.
