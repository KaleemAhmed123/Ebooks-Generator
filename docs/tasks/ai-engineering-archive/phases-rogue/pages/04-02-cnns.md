# AI Engineering: From Scratch

## Convolutional Neural Networks (CNNs)

Stacking convolutions allows a network to build hierarchical representations. 
- **Layer 1** learns edges and colors.
- **Layer 5** learns textures and basic shapes.
- **Layer 50** learns object parts (e.g., dog faces, car wheels).

### The Receptive Field

A single 3x3 convolution looks at 9 pixels. If you stack a second 3x3 convolution on top of it, the new layer effectively "sees" a 5x5 patch of the original image. By the end of a deep CNN, a single neuron's receptive field covers the entire image.

### Modern CNN Architecture

Classic networks like VGG proved that "3x3 convolutions all the way down" is the optimal design. Two stacked 3x3 convs see the same 5x5 area as one 5x5 conv, but use fewer parameters and insert an extra non-linear activation in between.

**Residual Networks (ResNets):**
As CNNs got deeper, gradients vanished. ResNets solved this by adding skip connections: $x_{out} = \text{Layer}(x) + x$. This gives the gradient an uninterrupted highway to flow backward, allowing networks to scale to 100+ layers.

Today, CNNs like ConvNeXt remain the default for fast, edge-device computer vision.
