### Where SVD appears in AI

| Application | How SVD is used |
|---|---|
| **Image compression** | Truncate to rank k; store k singular values + vectors instead of all pixels |
| **Word embeddings (LSA)** | SVD on word-document co-occurrence matrix extracts latent topics |
| **Recommendation systems** | SVD on user-item rating matrix finds latent preference factors |
| **LoRA fine-tuning** | Weight updates expressed as low-rank products AB (rank-r SVD structure) |
| **Pseudoinverse** | `A⁺ = VΣ⁺Uᵀ`; inverts any matrix for least-squares solutions |

:::mint
```python
import numpy as np
U, s, Vt = np.linalg.svd(A, full_matrices=False)
k = 50
A_approx = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]  # rank-k approximation
```
:::

:::note
PCA is a special case of SVD: applying SVD to the mean-centred data matrix X gives the same principal components as eigendecomposing XᵀX. `sklearn.decomposition.PCA` uses `scipy.linalg.svd` internally, not `eigh`, because SVD is numerically more stable for ill-conditioned data.
:::
