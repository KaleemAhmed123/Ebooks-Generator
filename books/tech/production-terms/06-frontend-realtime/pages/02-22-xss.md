## XSS

*cross-site scripting*

Attacker-controlled input executing as script in another user's browser, with
full access to their session.

A comment containing an `onerror` handler, rendered through
`dangerouslySetInnerHTML`, steals the session of every reader who loads the
page.

| Kind | Arrives via |
|---|---|
| Stored | saved in the database, hits every viewer |
| Reflected | bounced back from a URL parameter |
| DOM-based | a sink like `innerHTML`, never touching the server |

**Defence is layered because each layer fails differently.** Escape on output so
the payload never becomes markup, set a CSP so an injected script cannot run
anyway, and mark session cookies `HttpOnly` so a script that does run cannot
read them.
