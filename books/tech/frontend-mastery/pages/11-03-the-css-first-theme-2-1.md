### The namespaces

The prefix on the variable name decides which utilities Tailwind generates. These are the ones you will reach for.

| Namespace | Generates |
|---|---|
| `--color-*` | `bg-*`, `text-*`, `border-*`, `fill-*`, `ring-*` |
| `--font-*` | `font-sans`, `font-display` |
| `--text-*` | `text-xl`, `text-2xl` (font size) |
| `--font-weight-*` | `font-bold`, `font-medium` |
| `--tracking-*` | `tracking-wide` |
| `--leading-*` | `leading-relaxed` |
| `--spacing-*` | `p-4`, `mb-8`, `gap-2`, `max-h-16` |
| `--radius-*` | `rounded-lg` |
| `--shadow-*` | `shadow-md` |
| `--breakpoint-*` | the `sm:`, `md:`, `lg:` variants |
| `--container-*` | container query variants and `max-w-*` |
| `--animate-*` | `animate-spin` |
| `--ease-*` | `ease-out` |
