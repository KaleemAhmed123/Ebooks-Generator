## AGENTS.md and MCP

By 2026 the interesting question stopped being which assistant you use. It is
what your repository tells any assistant before it writes a line.

The numbers behind that shift: roughly **29% of code** written by State of JS
respondents was AI-generated by the end of 2025, up from 20% the year before.
Developers report reaching for AI on around **60% of their work** while being
able to fully hand off only **0 to 20% of tasks**. The gap between those two
figures is review, and it is where the job now lives.

Two conventions emerged to close part of that gap: a file that carries your
standards, and a protocol that gives the model real context instead of guesses.

### `AGENTS.md`

A markdown file at the repository root that coding agents read before working.
Think of it as the onboarding document you would give a contractor on day one,
except it is read every single time.

It became a convention because every tool had invented its own file, and nobody
wanted to maintain four of them.

```markdown
# AGENTS.md

## Stack
Next.js 16 App Router, React 19, TypeScript 7, Tailwind 4, Vitest, Playwright.
Package manager is pnpm. Node 24.

## Commands
- `pnpm dev` for the dev server
- `pnpm test` runs Vitest, `pnpm test:e2e` runs Playwright
- `pnpm lint` and `pnpm typecheck` must both pass before a commit
```
