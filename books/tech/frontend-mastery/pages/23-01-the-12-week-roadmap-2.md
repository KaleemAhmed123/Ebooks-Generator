### Weeks 9-10: The Network Layer
- **The Goal:** Stop writing `useEffect` for data fetching.
- **The Project:** Build a HackerNews clone using the public HackerNews API.
- **The Rules:** You must use React Query (TanStack Query) for all data fetching. Implement pagination and infinite scrolling.
- **Why?** You will master caching, stale-while-revalidate strategies, and optimistic UI updates.

### Weeks 11-12: The Enterprise Backend-for-Frontend
- **The Goal:** SSR, SEO, and Security.
- **The Project:** Migrate your HackerNews clone to Next.js App Router.
- **The Rules:** Implement Auth.js (NextAuth) for Google Login. Convert your data fetching components into React Server Components (RSC).
- **Why?** You will cross the boundary from a standard "Frontend Developer" to a Full-Stack Product Engineer.
