## L1 vs L2 regularization — what each does to the weights, and when you pick which.

- **Regularization** adds a penalty on weight size to the loss, discouraging the model from fitting noise.
- **L2 (ridge)** penalises `Σ wᵢ²`. It shrinks all weights smoothly toward zero but rarely to exactly zero. Good default; keeps every feature, just damped.
- **L1 (lasso)** penalises `Σ |wᵢ|`. Its gradient is constant, so it pushes small weights *all the way* to zero — producing a **sparse** model that does automatic feature selection.
- Pick **L1** when you want a smaller, interpretable model or suspect most features are useless. Pick **L2** when features are correlated and all carry some signal. **Elastic net** blends both.

:::mint
```text
L2:  loss + λ Σ wᵢ²      -> small, dense weights
L1:  loss + λ Σ |wᵢ|     -> many weights exactly 0 (sparse)
```
:::

:::interview
What's really being tested:

that you know *why* L1 produces zeros (constant-magnitude gradient / diamond-shaped constraint hits the axes) — not just that "L1 is sparse."
:::
