## What is MCP (Model Context Protocol) and why does it matter?

- **MCP** is an open standard for how an LLM app connects to tools and data. Before it, every app wrote custom integrations for every tool — an **M×N** problem (M apps × N tools). [VERIFY: MCP spec/version details — evolves fast.]
- MCP turns that into **M + N**: a tool is exposed once as an **MCP server**; any MCP-compatible **client** (the app/agent) can use it. Write the integration once, reuse everywhere.
- Architecture: a **host** (the app) runs **clients**, each connecting to a **server** that exposes **primitives** — **tools** (callable functions), **resources** (readable data), and **prompts** (reusable templates). Communication is JSON-RPC over stdio or HTTP.
- Why it matters: a standard, composable tool ecosystem — plug any MCP server (GitHub, a database, a filesystem) into any agent without bespoke glue.
