## Glossary: E – F

| Term | Means | In |
|---|---|---|
| **Exponential backoff** | retrying a failed request after growing waits (1s, 2s, 4s) | B1 |
| **Exposure bias** | the mismatch from training only on true histories (teacher forcing) but feeding the model its own imperfect outputs at inference | B3 |
| **Extractive summarization** | building a summary by selecting sentences directly from the source | B3 |
| **F1 score** | the harmonic mean of precision and recall | B1 |
| **fairness impossibility** | The result that calibration and equal error rates cannot all hold across groups with different base rates, so a fairness criterion must be chosen | B6 |
| **false success** | An agent reporting a task done when it silently failed; the most dangerous agent failure mode | B5 |
| **FastMCP** | High-level MCP server API where a decorated function's type hints and docstring become the tool schema | B5 |
| **fastText** | an embedding method that represents a word as the sum of its character n-grams, handling unseen words | B3 |
| **Feature engineering** | turning raw data into inputs a model uses well | B1 |
| **Feature map** | the grid a convolution outputs, showing where its pattern appears | B2 |
| **Feature selection** | keeping the informative features and dropping the rest | B1 |
| **Feed-forward network (FFN)** | the per-token two-layer network in a transformer block that transforms each token's content | B3 |
