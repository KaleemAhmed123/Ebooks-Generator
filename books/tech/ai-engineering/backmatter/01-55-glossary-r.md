## Glossary: R

| Term | Means | In |
|---|---|---|
| **RLVR (RL from verifiable rewards)** | RL where correctness is cheap to check (math, code), used to train reasoning models | B4 |
| **RMSNorm** | a cheaper LayerNorm variant that skips mean-centering, common in modern LLMs | B3 |
| **RNN (recurrent neural network)** | a network that reads a sequence step by step, carrying a running hidden state | B3 |
| **role specialization** | Splitting work into agents with distinct responsibilities, prompts, tools, and often models | B5 |
| **rollback** | Returning to a known-good checkpoint after a bad step | B5 |
| **roofline model** | A performance model plotting achievable throughput against arithmetic intensity, showing where a workload is memory-bound versus compute-bound | B6 |
| **roots (MCP)** | URI boundaries a client declares to confine a server's filesystem/resource access (least privilege) | B5 |
| **RoPE (rotary positional encoding)** | encoding position by rotating query and key vectors; standard in modern LLMs | B3 |
| **ROUGE** | a summarization metric scoring overlap with a human reference | B3 |
| **routine** | A focused agent defined by a specific set of instructions and tools for one job | B5 |
| **routing layer** | A layer that picks the model per request by task, cost, latency, or fallback; also a proxy for many providers | B5 |
| **routing (workflow)** | Classifying an input and dispatching it to a specialized handler | B5 |
