## Glossary: N – O

| Term | Means | In |
|---|---|---|
| **Nonlinearity** | a non-straight-line function; what makes network depth useful | B2 |
| **non-stationarity** | In MARL, the moving-target problem that every agent's environment changes as all agents learn simultaneously | B5 |
| **non-stationary** | In MARL, the environment appearing to change to one agent because the other agents keep adapting | B5 |
| **Normal equation** | solving for the exact best regression weights in one step | B1 |
| **Normalizing** | dividing a vector by its length to make it unit length | B1 |
| **Nucleus sampling (top-p)** | sampling from the smallest set of tokens whose probabilities sum to p | B4 |
| **Nyquist rule** | a sample rate captures frequencies only up to half its value | B2 |
| **OAuth 2.1** | The delegated-authorization profile MCP adopted for remote servers; issues scoped tokens | B5 |
| **Object detection** | finding what objects are in an image and where, as boxes | B2 |
| **observability (agents)** | Capturing every model call, tool call, and decision of agent runs as traces for debugging, cost, and quality | B5 |
| **OCR (optical character recognition)** | converting images of text into machine-readable characters | B2 · B5 |
| **omni model** | A model taking any input modality and producing any output modality, often in real time | B5 |
