## Glossary: N

| Term | Means | In |
|---|---|---|
| **Needle in a haystack (NIAH)** | a long-context test that hides one fact in a large document for the model to retrieve | B3 |
| **Negative sampling** | training on a few random non-neighbor words instead of a full-vocabulary softmax (word2vec) | B3 |
| **negotiation** | Reaching agreement between agents with opposed goals, via offers and counter-offers | B5 |
| **NeRF (neural radiance field)** | a network encoding a 3D scene for rendering new viewpoints | B2 |
| **network topology** | Multi-agent shape where agents talk peer-to-peer with no central coordinator | B5 |
| **Neural audio codec** | a network compressing sound into discrete tokens and rebuilding it | B2 |
| **n-gram model** | a language model estimating the next word from the previous n−1 words by counting | B3 |
| **NIST AI RMF** | The US National Institute of Standards and Technology's voluntary AI Risk Management Framework, organised into Govern, Map, Measure, and Manage functions | B6 |
| **NLP (natural language processing)** | getting computers to work with human language as data | B3 |
| **NMS (non-max suppression)** | removing overlapping duplicate detection boxes | B2 |
| **nn.Module** | the PyTorch base class for building models | B2 |
| **node (LangGraph)** | A function that reads the shared state and returns an update; a step in the graph | B5 |
