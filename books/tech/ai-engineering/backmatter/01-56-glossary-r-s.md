## Glossary: R – S

| Term | Means | In |
|---|---|---|
| **RRF (reciprocal rank fusion)** | merging ranked lists using only ranks, `Σ 1/(k+rank)`, needing no score calibration | B4 |
| **RSP (Responsible Scaling Policy)** | Framework tying required safeguards to measured model capability (Anthropic; ASL levels) | B5 · B6 |
| **RT-2** | Google's first internet-scale vision-language-action model (2023) | B5 |
| **Ruff** | a fast Python linter and formatter | B1 |
| **rug pull** | An MCP server silently changing a tool's behavior after it was approved | B5 |
| **RULER** | a long-context benchmark testing reasoning over scattered facts, not just single-fact retrieval | B3 |
| **Runner (OpenAI SDK)** | Component that runs the agent loop until a final output, enforcing max-turns | B5 |
| **RVQ (residual vector quantization)** | quantising a signal in stacked layers, each refining the last's error | B2 |
| **Saddle point** | a spot down in some directions and up in others; not a true trap | B1 |
| **safety case** | A written argument that a deployment is acceptably safe under worst-case assumptions, structured around incapability, monitoring, and illegibility | B6 |
| **Sample rate** | audio readings taken per second, in hertz | B2 |
| **sampling (MCP)** | A server asking the client to run an LLM completion on its behalf, under the host's control | B5 |
