## Glossary: U – V

| Term | Means | In |
|---|---|---|
| **Unsupervised learning** | finding structure in data with no labels | B1 |
| **uv** | a fast Rust-based Python package, environment, and version manager | B1 |
| **VAD (voice activity detection)** | detecting whether speech is present right now | B2 · B5 |
| **Validation loss** | loss measured on held-out data, used to catch overfitting | B2 |
| **Validation set** | data used to tune choices, without training on it | B1 |
| **Value / Q-value** | expected total discounted reward from a state (V), or from a state after a specific action (Q) | B4 |
| **Vanishing / exploding gradient** | gradients shrinking to nothing or blowing up over long sequences or deep stacks | B3 |
| **Vanishing gradient** | gradients shrinking toward zero through deep layers, stalling learning | B1 |
| **Vanishing gradients** | gradients shrinking toward zero over depth, stalling learning | B2 |
| **Variance (error)** | error from a model so flexible it memorizes noise; causes overfitting | B1 |
| **Vector** | an ordered list of numbers | B1 |
| **Vector database** | a store that indexes embeddings and answers nearest-neighbour queries (Pinecone, Weaviate, Qdrant, Milvus, pgvector) | B4 |
