## Glossary: S

| Term | Means | In |
|---|---|---|
| **Stacking** | combining different model types with a final model | B1 |
| **Standard deviation** | the spread of a distribution; the square root of variance | B1 |
| **STaR (Self-Taught Reasoner)** | Self-improvement by generating reasoning, keeping only correct chains, and fine-tuning on them | B5 |
| **Stationarity** | whether a time series' statistics stay constant over time | B1 |
| **stdio** | MCP's local transport: the server runs as a subprocess communicating over standard input/output | B5 |
| **Stemming** | chopping word suffixes with blind rules to get a rough root | B3 |
| **stigmergy** | Coordination through marks left in a shared environment rather than direct messaging | B5 |
| **Store (LangGraph)** | Cross-thread key-value store (optionally with vector search) for long-term memory shared across conversations | B5 |
| **Streamable HTTP** | MCP's remote transport (2025 revision) where the client POSTs JSON-RPC and the server may stream back | B5 |
| **Stride** | how far a kernel jumps between positions; a stride above 1 shrinks the output | B2 |
| **structured output** | Forcing a model's final answer into a fixed, validated JSON shape (no function runs) | B5 |
| **Structured outputs** | model output constrained to a valid machine-readable schema such as JSON | B3 |
