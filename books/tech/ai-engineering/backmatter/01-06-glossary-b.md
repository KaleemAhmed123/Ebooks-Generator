## Glossary: B

| Term | Means | In |
|---|---|---|
| **Batch normalization** | rescaling a layer's outputs across the batch to a steady mean and spread | B2 |
| **Bayes' theorem** | the rule for updating a belief (prior) into a posterior using evidence | B1 |
| **Beam search** | decoding that keeps the top-b partial sequences at each step and returns the highest-probability full sequence; suited to closed tasks like translation, poor for open-ended text | B4 |
| **Bellman equation** | value written in terms of itself one step ahead: reward now plus discounted value of the next state | B4 |
| **Bernoulli distribution** | the distribution of a single yes/no outcome | B1 |
| **BERT** | an encoder-only transformer pretrained with masked language modeling; built for understanding, not generation | B3 |
| **Bias (error)** | error from a model too simple to fit the pattern; causes underfitting | B1 |
| **Bi-encoder** | an embedding model that encodes query and document separately for fast comparison; contrast cross-encoder | B4 · B6 |
| **BIO tagging** | labeling each token as Begin, Inside, or Outside an entity, so multi-word entities are marked cleanly | B3 |
| **Bit depth** | how finely each audio sample's amplitude is measured | B2 |
| **blackboard** | Shared workspace all agents read from and write to, coordinating through it instead of direct messages | B5 |
| **Blackwell** | NVIDIA's 2025–2026 datacentre GPU generation (B200, GB200), notable for native FP4 support and larger, faster memory | B6 |
