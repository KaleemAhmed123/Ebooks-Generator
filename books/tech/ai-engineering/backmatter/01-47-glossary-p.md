## Glossary: P

| Term | Means | In |
|---|---|---|
| **PEFT (parameter-efficient fine-tuning)** | fine-tuning that trains a small number of new parameters and freezes the rest | B4 |
| **Perceiver Resampler** | Module using a fixed set of learned latents to cross-attend to variable visual input and emit a fixed token count (Flamingo) | B5 |
| **Perceptron** | a single neuron; the simplest neural network | B2 |
| **performative** | The intent label on an ACL message (inform, request, propose) telling the receiver how to interpret it | B5 |
| **permission mode** | A setting for how much an agent may do unsupervised (read-only, ask-each-action, accept-edits, full-auto) | B5 |
| **Perplexity** | a measure of language-model loss: roughly how many tokens the model is choosing between at each step; lower is better | B4 · B6 |
| **PF (Preparedness Framework)** | OpenAI's safety framework defining criteria for tracked capabilities and separating capability from safeguard reports; v2 as of 2026 | B6 |
| **pheromone** | The shared trail ants leave in ACO; a form of stigmergy (coordination through the environment) | B5 |
| **Pipecat / LiveKit** | Frameworks handling real-time voice-agent orchestration (streaming, VAD, turn-taking, barge-in) | B5 |
| **pipeline parallelism (PP)** | Splitting a model's layers into sequential stages on different GPUs to fit models too large even for tensor parallelism within a node | B6 |
| **Pixtral** | Mistral open VLM with a from-scratch native-resolution vision encoder (no CLIP) | B5 |
| **plan-and-execute** | Pattern splitting a planner (writes the full plan) from an executor (carries out steps) | B5 |
