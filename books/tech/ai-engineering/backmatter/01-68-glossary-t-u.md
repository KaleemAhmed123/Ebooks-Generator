## Glossary: T – U

| Term | Means | In |
|---|---|---|
| **Triplet loss** | a metric-learning loss using an anchor, a positive, and a negative example | B2 |
| **t-SNE** | a method for plotting clusters; for visualization only | B1 |
| **TTFT (Time To First Token)** | The delay from request to the first output token; set by prefill, grows with prompt length, and dominates perceived responsiveness | B6 |
| **Turn-taking** | deciding when a speaker has finished so a system can reply | B2 |
| **UMAP** | a faster alternative to t-SNE that keeps some global structure | B1 |
| **Underfitting** | a model too simple to capture the pattern | B1 |
| **U-Net** | an encoder–decoder with skip connections that produces full-resolution outputs | B2 |
| **unified understand-and-generate** | Models aiming to both read and produce images well without a quality trade-off | B5 |
| **Uniform distribution** | every value equally likely | B1 |
| **unit economics** | Cost per business outcome (per resolved ticket, per task, per user), the metric that decides whether an LLM feature is viable — not cost per token | B6 |
| **Unit vector** | a vector of length exactly 1 | B1 |
| **Universal approximation theorem** | one hidden layer of enough neurons can approximate any continuous function | B2 |
