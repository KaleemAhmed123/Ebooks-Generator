## Glossary: C

| Term | Means | In |
|---|---|---|
| **Contrastive learning** | training that pulls matching pairs together and pushes non-matching pairs apart | B2 · B3 · B5 |
| **Convex** | a single-bowl function where gradient descent always finds the best answer | B1 |
| **Convolution** | sliding a small shared weight grid across an input to build a feature map | B2 |
| **Coreference resolution** | deciding which words (often pronouns) refer to the same real-world thing | B3 |
| **Correlation** | how strongly two variables move together, from −1 to +1; not causation | B1 |
| **corrigibility** | A model's property of remaining open to correction and shutdown; a deliberate design target, since instrumental convergence predicts capable agents resist it | B6 |
| **Cosine decay** | a learning-rate schedule that eases the rate down a cosine curve toward zero | B2 |
| **Cosine similarity** | the dot product of two unit vectors; similarity by angle | B1 · B3 |
| **Cost function** | see loss; a number measuring how wrong the model is | B1 |
| **cost governor** | A hard, in-path budget (tokens, steps, time, dollars) that halts an agent before runaway spend | B5 |
| **counterfactual fairness** | A fairness criterion requiring the outcome to be unchanged in a hypothetical world where the individual's protected attribute differed | B6 |
| **Credit assignment** | the RL problem of deciding which earlier actions deserve credit for a reward that arrives much later | B4 · B5 |
