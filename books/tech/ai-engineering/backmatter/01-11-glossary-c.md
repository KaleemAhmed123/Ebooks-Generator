## Glossary: C

| Term | Means | In |
|---|---|---|
| **cold start** | The 40–120 s delay before a fresh GPU pod can serve, spent loading and warming the model into VRAM | B6 |
| **collective operations** | Coordinated multi-GPU communication primitives (all-reduce, all-gather, reduce-scatter) that every distributed-training strategy is built from | B6 |
| **ColPali** | Vision-native retrieval that embeds page images directly (many vectors per page, late interaction), skipping OCR | B5 |
| **Columnar** | storing a table by column so reads touch only the needed columns | B1 |
| **Commit** | a saved snapshot of your files in git | B1 |
| **competitor-adjustment clause** | A provision in a safety framework permitting the lab to relax requirements if a peer ships comparable capability without comparable safeguards | B6 |
| **compliance gap** | In alignment faking, the difference in a model's compliance rate between conditions it believes are used for training and those it believes are not | B6 |
| **component eval** | Evaluating each individual piece of an agent (retriever, router, a tool) in isolation | B5 |
| **Computational graph** | a record of operations used to compute gradients backward | B1 |
| **computer-use agent** | Agent that operates software by reading screenshots and emitting UI actions (click, type, scroll) | B5 |
| **Conda** | an environment manager that also handles non-Python dependencies | B1 |
| **conditional edge** | A LangGraph edge that routes to different nodes based on the state, enabling loops and branching | B5 |
