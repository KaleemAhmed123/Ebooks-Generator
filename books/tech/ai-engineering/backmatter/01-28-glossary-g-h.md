## Glossary: G – H

| Term | Means | In |
|---|---|---|
| **guardrail** | A validation check on an agent's inputs or outputs that can halt or redirect it | B5 |
| **Guardrails** | checks around a model that screen inputs and outputs for unsafe, off-topic, or ungrounded content | B4 · B5 |
| **guided decoding** | Constraining generation to a grammar or JSON Schema by masking invalid tokens at each step, guaranteeing well-formed output. Also *structured decoding* | B6 |
| **Hallucination** | a model stating fluent, confident information that is not supported by its input or the facts | B3 |
| **handoff** | One agent transferring the whole conversation to another; peer-to-peer control transfer | B5 |
| **HDF5** | a format for efficient slices of large numeric arrays | B1 |
| **Head (attention head)** | one of several parallel attention operations, each learning a different way tokens relate | B3 |
| **hedged request** | Sending a duplicate request to another instance after a delay and taking whichever returns first, cutting tail latency at a small extra load | B6 |
| **Hibiki** | Kyutai's real-time speech-to-speech translation model | B2 |
| **Hidden layer** | a layer between the input and the output | B2 |
| **hierarchical architecture** | Supervisors of supervisors; layered delegation that spreads coordination and context load | B5 |
| **hierarchy (multi-agent)** | Nested supervisors coordinating sub-supervisors and workers, scaling coordination like an org chart | B5 |
