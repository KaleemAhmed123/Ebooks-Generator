## Glossary: M

| Term | Means | In |
|---|---|---|
| **moderation system** | The production pipeline that screens inputs and outputs against a policy and acts (block, redact, escalate), with human review for borderline cases | B6 |
| **Molmo** | Open VLM from AI2 notable for fully open PixMo data and pointing (coordinate) capability | B5 |
| **Momentum** | averaging recent gradients so descent builds speed in steady directions | B1 |
| **Monocular depth** | estimating depth from a single image | B2 |
| **Monte-Carlo methods** | estimating value by playing full episodes and averaging the returns that actually followed | B4 |
| **Monte Carlo Tree Search (MCTS)** | Search that balances exploration and exploitation over a tree; the engine of LATS and game AI | B5 |
| **Moshi** | Kyutai's full-duplex speech-text dialogue model | B2 |
| **MOS (mean opinion score)** | a human 1–5 rating of audio naturalness | B2 |
| **MQA (multi-query attention)** | attention where all heads share a single key/value set | B3 |
| **M-RoPE** | Multimodal rotary position embedding encoding position along time, height, and width separately (Qwen-VL) | B5 |
| **MSE (mean squared error)** | the average squared gap between prediction and truth | B1 · B2 |
| **multi-agent debate** | Several agents answering, then critiquing each other across rounds to converge more accurately | B5 |
