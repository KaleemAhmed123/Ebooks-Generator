## Glossary: P

| Term | Means | In |
|---|---|---|
| **Preparedness Framework** | OpenAI's capability-gated risk framework across categories like cyber, CBRN, and autonomy | B5 |
| **Prior** | the belief in a hypothesis before evidence | B1 |
| **Probability** | a number from 0 to 1 giving how likely an outcome is | B1 |
| **procedural memory** | Memory of how to do things: learned, reusable skills (e.g. Voyager's code skill library) | B5 |
| **progressive disclosure** | Loading skill detail in layers (name always, body when relevant, scripts when run) to save context | B5 |
| **Projection** | flattening a vector onto a lower-dimensional space | B1 |
| **Projector** | the small network mapping image features into an LLM's token space in a VLM | B2 |
| **projector (VLM)** | A small learned network mapping vision-encoder features into the LLM's token embedding space (LLaVA's linear/MLP connector) | B5 |
| **Prompt caching** | reusing the computed KV cache of a fixed prompt prefix across requests at a large discount | B4 · B6 |
| **prompt chaining** | Workflow decomposing a task into a fixed sequence of LLM calls, each on the previous output | B5 |
| **prompt extraction** | An attack that tricks a model into revealing its hidden system prompt; defended by keeping no secrets in the prompt rather than by prompt secrecy | B6 |
| **Prompt injection** | an attack where untrusted text carries instructions the model obeys, overriding the developer's | B4 · B5 · B6 |
