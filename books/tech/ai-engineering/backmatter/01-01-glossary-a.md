## Glossary: A

| Term | Means | In |
|---|---|---|
| **A2A (Agent2Agent)** | Open protocol for agents built by different teams to discover and delegate tasks to each other, via Agent Cards | B5 |
| **Abstractive summarization** | writing new sentences that capture a text's gist, rather than copying existing ones | B3 |
| **Accuracy** | fraction of predictions that are correct; misleading on imbalanced data | B1 |
| **ACL (Agent Communication Language)** | FIPA standard where each message carries a performative (its intent) alongside its content | B5 |
| **ACO (Ant Colony Optimization)** | Swarm algorithm where agents reinforce good paths with virtual pheromone, so better routes accumulate more use | B5 |
| **action constitution** | Explicit natural-language principles governing what an agent may and may not do, checked before consequential actions | B5 |
| **action expert** | A small continuous-action generator (flow-matching or diffusion) replacing a VLA's binned action head to produce smooth, dexterous motion (π0) | B5 |
| **action tokenization** | Discretising continuous robot controls into bins so a model predicts the next action token like a word (used by VLAs) | B5 |
| **Activation function** | the nonlinear bend applied to a neuron's output; what lets stacked layers add new shape | B2 |
| **Actor-critic** | an RL method pairing a policy (actor) that chooses actions with a value estimate (critic) that judges them, training the actor on the advantage | B4 |
| **actor model** | Concurrency design of isolated units that communicate only by asynchronous messages, with no shared memory; AutoGen's basis | B5 |
| **Adam** | optimizer giving each weight its own adaptive learning rate; the default for transformers | B1 |
