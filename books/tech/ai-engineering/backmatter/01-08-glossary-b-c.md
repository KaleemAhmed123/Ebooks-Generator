## Glossary: B – C

| Term | Means | In |
|---|---|---|
| **Byte-level BPE** | BPE run over raw bytes, so any text in any language encodes with no unknown tokens | B3 |
| **Byzantine fault tolerance (BFT)** | Reaching agreement despite participants that may lie or fail arbitrarily; needs ≥3f+1 members to tolerate f bad ones | B5 |
| **C2PA (Content Credentials)** | A standard for cryptographically signed provenance metadata describing how a piece of media was created and edited | B6 |
| **calibration (fairness)** | A fairness criterion where a given risk score means the same probability of the outcome across groups | B6 |
| **canary** | A small watched slice of traffic that receives a change first, so a bad update fails on a fraction, not everyone | B5 |
| **canary deployment** | Routing a small fraction of traffic to a new version first, widening only if metrics hold, else rolling back | B5 · B6 |
| **capabilities (MCP)** | Features each side declares in the initialize handshake; both must support one before it is used | B5 |
| **cascade** | A routing pattern that tries a cheap model first and escalates to a stronger one only when the cheap answer is judged insufficient | B6 |
| **cascade failure** | One agent's error propagating through a multi-agent system until the collective agrees on the mistake | B5 |
| **cascade (model routing)** | Trying a cheap model first and escalating to an expensive one only when its output fails a check | B5 |
| **catastrophic forgetting** | When fine-tuning on a narrow dataset makes a model lose general capability it had from pretraining | B6 |
| **Categorical distribution** | the distribution over one pick from several classes | B1 |
