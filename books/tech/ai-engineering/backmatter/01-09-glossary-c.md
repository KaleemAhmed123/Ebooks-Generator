## Glossary: C

| Term | Means | In |
|---|---|---|
| **Causal language modeling** | the next-token-prediction training objective used by GPT-style decoders | B3 |
| **Causal masking** | blocking each token from attending to later tokens, required for left-to-right generation | B3 |
| **Causal model** | one that may use only past and present input, never future; required for streaming | B2 |
| **CBOW** | a word2vec variant that predicts a center word from its surrounding context | B3 |
| **Central limit theorem** | sums of many small independent effects tend toward a Gaussian | B1 |
| **Chain-of-thought (CoT)** | prompting the model to write intermediate reasoning steps before its answer, raising accuracy on hard tasks | B4 |
| **Chain rule** | differentiating nested functions by multiplying their slopes | B1 |
| **Chameleon** | Meta early-fusion model that tokenises images into a shared vocabulary with text for one next-token transformer | B5 |
| **ChartQA** | Benchmark for reading and reasoning over chart images | B5 |
| **checkpointer** | LangGraph component that persists graph state after each node, enabling resume, human-in-the-loop, and time travel | B5 |
| **checkpointing** | Persisting workflow state at each step so a run can resume after a crash rather than restart | B5 |
| **Chinchilla** | the 2022 result that compute-optimal training uses roughly 20 training tokens per parameter | B3 |
