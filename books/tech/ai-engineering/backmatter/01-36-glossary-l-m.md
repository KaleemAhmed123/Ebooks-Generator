## Glossary: L – M

| Term | Means | In |
|---|---|---|
| **long-horizon** | A task running hundreds of steps or many hours, where error compounding dominates | B5 |
| **long-horizon agent** | An agent working autonomously over many steps and a long time on one task | B5 |
| **LoRA** | low-rank adaptation; cheap fine-tuning by storing weight changes as thin matrices | B1 |
| **LoRA (low-rank adaptation)** | fine-tuning by freezing the base weights and training two small low-rank matrices beside each large one | B4 |
| **Loss** | a single number measuring model error; training minimizes it | B1 · B2 |
| **loss masking** | In SFT, ignoring the prompt tokens in the loss (label them −100) so the model learns to produce responses, not predict instructions | B6 |
| **Lost in the middle** | the tendency of long-context models to use facts at the start and end but ignore the middle | B3 · B4 · B5 |
| **LSTM (long short-term memory)** | a recurrent cell with a gated memory belt that carries information across long sequences | B3 |
| **Machine learning** | programs that learn their rules from data instead of hand-coding | B1 |
| **Machine translation** | automatically translating text from one language to another | B3 |
| **machine unlearning** | Removing specific knowledge or capability from a trained model (e.g. RMU) without full retraining, aiming to preserve general ability | B6 |
| **MADDPG** | Multi-agent actor-critic (CTDE) with per-agent actors and a centralized critic | B5 |
