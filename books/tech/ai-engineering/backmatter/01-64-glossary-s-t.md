## Glossary: S – T

| Term | Means | In |
|---|---|---|
| **swarm intelligence** | Collective problem-solving by many simple agents following local rules (PSO, ACO) | B5 |
| **SWE-bench** | Benchmark where an agent must patch a real repository so its hidden tests pass; the headline coding-agent metric | B5 |
| **sycophancy** | A model telling users what they want to hear rather than what is true, a direct product of rewarding rater approval in RLHF | B6 |
| **system card** | A structured document disclosing a deployed system (model plus scaffolding and safeguards), its architecture, safety measures, and red-team results | B6 |
| **T5** | an encoder–decoder transformer that casts every NLP task as text-in, text-out | B3 |
| **Tanh** | an activation squashing values into (−1, 1), centred on zero | B2 |
| **task horizon** | The length of task (in human time) a model can complete reliably; METR's autonomy metric | B5 |
| **TCO (total cost of ownership)** | The full cost of a system including engineering, reliability, and opportunity cost, not just the per-token or hardware price | B6 |
| **Teacher forcing** | feeding the true previous token (not the model's guess) as input during sequence training, giving a clean signal and parallel training | B3 |
| **Temperature** | a decoding knob dividing logits before softmax: below 1 sharpens, above 1 flattens, 0 is greedy | B4 |
| **Temporal** | A durable-execution workflow engine that persists each step and replays to resume without repeating side effects | B5 |
| **temporal grounding** | Identifying the timestamp in a video where a described event occurs | B5 |
