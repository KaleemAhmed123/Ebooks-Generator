## Glossary: S

| Term | Means | In |
|---|---|---|
| **semantic caching** | Returning a stored answer when a new query is embedding-similar to a past one, skipping the model entirely on a hit | B6 |
| **semantic memory** | Memory of general facts and knowledge, distilled from many episodes (e.g. 'the user prefers Python') | B5 |
| **Semantic search** | retrieval by embedding query and documents into vectors and comparing meaning | B3 |
| **Semantic segmentation** | labelling every pixel of an image with a class | B2 |
| **Sentiment analysis** | classifying the emotional polarity (positive/negative) of a text | B3 |
| **seq2seq (sequence to sequence)** | the encoder–decoder pattern mapping an input sequence to an output sequence | B3 |
| **Sequence-to-sequence** | reading an input sequence and generating an output sequence | B2 |
| **server (MCP)** | A program exposing tools, resources, and prompts; knows nothing about the model | B5 |
| **Serving engine** | software that wraps a model in an API, handling batching, KV-cache management, and token streaming (vLLM, SGLang, TensorRT-LLM) | B4 |
| **session (agent)** | Automatic conversation history across turns providing short-term memory | B5 |
| **set-of-marks** | Overlaying numbered labels on UI/image elements so a VLM selects a number instead of predicting raw coordinates | B5 |
| **SFT (supervised fine-tuning)** | training a base model on instruction→response examples so it follows instructions | B4 |
