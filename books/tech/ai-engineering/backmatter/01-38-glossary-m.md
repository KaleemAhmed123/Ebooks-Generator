## Glossary: M

| Term | Means | In |
|---|---|---|
| **Mask R-CNN** | a classic instance-segmentation model: detect boxes, then mask each object | B2 |
| **MAST** | A taxonomy of multi-agent system failure modes, most of them coordination rather than reasoning failures | B5 |
| **Matrix** | a grid of numbers with rows and columns | B1 |
| **Matrix multiplication** | combining matrices via dot products of rows and columns | B1 |
| **Maximum likelihood estimation (MLE)** | choosing the parameters that make the observed data most probable; the origin of cross-entropy and squared-error losses | B1 |
| **max_steps budget** | A cap on loop iterations that prevents an agent from running forever | B5 |
| **MCP (Model Context Protocol)** | Open standard for how AI apps connect to tools and data, turning M×N integrations into M+N | B5 |
| **MDP (Markov decision process)** | the formal RL problem: states, actions, transitions, rewards, and a discount factor | B4 |
| **Mean** | the average; the centre of a distribution | B1 |
| **mechanism design** | Engineering interaction rules so self-interested agents produce good collective outcomes (e.g. truthful bidding) | B5 |
| **Medusa / EAGLE** | speculative-decoding variants that add lightweight prediction heads to the target model instead of a separate draft model | B3 |
| **Mel spectrogram** | a spectrogram with its frequency axis warped to match human hearing | B2 |
