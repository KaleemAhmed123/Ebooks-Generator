## Glossary: M

| Term | Means | In |
|---|---|---|
| **MADDPG / QMIX / MAPPO** | Multi-agent RL algorithms for continuous control, cooperative value mixing, and multi-agent PPO respectively | B5 |
| **Magnitude (norm)** | the length of a vector | B1 |
| **managed LLM platform** | A hyperscaler LLM service (AWS Bedrock, Azure OpenAI, Google Vertex AI) offering models behind cloud controls and billing | B6 |
| **many-shot jailbreaking** | An attack that fills the context with many fabricated compliant examples so the model pattern-matches into answering a harmful request | B6 |
| **mAP (mean Average Precision)** | the standard detection metric combining label and box quality | B2 |
| **MAPPO** | Multi-agent PPO with a centralized value function; a strong, simple MARL baseline | B5 |
| **map-reduce** | Splitting work across parallel workers (map) and combining their outputs (reduce); the swarm pattern | B5 |
| **Margin** | the gap a support vector machine maximizes between classes | B1 |
| **Markov property** | the assumption that the next state depends only on the current state and action, not the full history | B4 |
| **MARL (multi-agent RL)** | Training several agents that learn while interacting, facing a non-stationary environment | B5 |
| **Masked image modelling** | self-supervised training that hides image patches and predicts them back | B2 |
| **Masked language modeling (MLM)** | pretraining by hiding tokens and predicting them from both-side context (BERT) | B3 |
