## Glossary: H – I

| Term | Means | In |
|---|---|---|
| **HNSW** | a layered-graph ANN index that navigates to nearest neighbours in roughly logarithmic hops | B4 |
| **host (MCP)** | The AI application that runs the model and hosts one client per connected server | B5 |
| **HTN (Hierarchical Task Network)** | Planning by decomposing a goal into sub-tasks down to primitive actions | B5 |
| **Hugging Face Hub** | the standard place to find, version, and share models and datasets | B1 |
| **hybrid memory** | Combining stores (vector, graph, context) for agent memory; mem0 is a common implementation | B5 |
| **Hybrid search** | combining keyword and semantic search and fusing their rankings | B3 · B4 |
| **HyDE (Hypothetical Document Embeddings)** | retrieving by embedding an LLM-drafted hypothetical answer instead of the raw question | B4 · B6 |
| **Hyperparameter** | a setting you choose before training (learning rate, tree depth) | B1 |
| **idempotency** | Designing an operation so running it twice has the same effect as once, making retries safe | B5 |
| **Identity switch** | a tracking error where two objects' IDs get swapped | B2 |
| **IDF (inverse document frequency)** | a weight that scales a word down the more documents it appears in | B3 |
| **Image (Docker)** | the frozen blueprint of a container's filesystem | B1 |
