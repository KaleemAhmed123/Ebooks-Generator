## Glossary: V – W

| Term | Means | In |
|---|---|---|
| **vmap** | the JAX transform that auto-vectorises a function over a batch | B2 |
| **Vocoder** | the text-to-speech stage that turns a spectrogram into a playable waveform | B2 |
| **voice agent** | An agent that listens and speaks in real time, wrapping an agent loop in a low-latency speech pipeline | B5 |
| **Voice cloning** | text-to-speech that mimics a specific person's voice from a short reference | B2 |
| **Voyager** | Minecraft LLM agent that wrote, stored, and composed its own skills, improving without retraining | B5 |
| **VQ tokenizer** | Vector-quantization autoencoder that maps image patches to discrete codebook indices, enabling early fusion | B5 |
| **VRAM** | a GPU's own memory; it decides what fits | B1 |
| **Warmup** | ramping the learning rate up from near zero early in training | B2 |
| **watermarking** | Embedding a detectable signal in generated text or images (e.g. SynthID) so AI output can be identified, robust only against non-adversarial use | B6 |
| **Waveform** | the raw list of audio amplitude samples | B2 |
| **weak-to-strong generalization** | Evidence that a weaker supervisor can partially elicit a stronger model's capability, a probe of scalable oversight (OpenAI, 2023) | B6 |
| **WebArena** | Benchmark for agents completing tasks on real websites | B5 |
