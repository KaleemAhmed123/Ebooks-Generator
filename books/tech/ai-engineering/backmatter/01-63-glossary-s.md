## Glossary: S

| Term | Means | In |
|---|---|---|
| **subagent** | A fresh-context helper an agent spawns for a sub-task, then discards | B5 |
| **subgraph** | A LangGraph graph used as a node inside another graph, enabling composition and reuse | B5 |
| **Subword tokenization** | splitting text into word pieces so common words stay whole and rare words break down | B3 |
| **summarization memory** | Long-term memory that replaces old turns with a rolling summary; gist-preserving but lossy | B5 |
| **Supervised learning** | learning from labelled input–answer pairs | B1 |
| **supervisor (orchestrator)** | A lead agent that delegates sub-tasks to workers and integrates their results | B5 |
| **supervisor pattern** | Multi-agent topology where one coordinator delegates to workers and synthesizes results (star topology) | B5 |
| **supply chain (MCP)** | The dependency risk of installing third-party servers (typosquatting, drift, unvetted publishers) | B5 |
| **Support vector** | the nearest points that define an SVM's boundary | B1 |
| **Support vector machine** | a classifier maximizing the margin between classes | B1 |
| **SVD** | singular value decomposition; factoring any matrix into rotate–stretch–rotate | B1 |
| **swarm** | Many identical agents working on disjoint pieces in parallel with little coordination | B5 |
