## Glossary: K – L

| Term | Means | In |
|---|---|---|
| **k-means** | clustering into `k` groups by repeatedly moving centres to their points' middle | B1 |
| **k-nearest neighbours** | classifying a point by the majority vote of its closest neighbours | B1 |
| **Knowledge graph** | a network of entities (nodes) connected by labeled relationships (edges) | B3 |
| **KTO (Kahneman-Tversky Optimization)** | preference alignment from single answers tagged desirable or undesirable, needing no pairs | B4 |
| **KV cache** | stored key and value vectors from earlier tokens, reused so each generation step does constant work | B3 |
| **L1 (Lasso)** | regularization penalizing absolute weight size; drives weights to zero | B1 |
| **L2 (Ridge)** | regularization penalizing squared weight size; shrinks weights smoothly | B1 |
| **Langfuse** | Open-source, self-hostable, OTel-native agent observability platform (traces, prompts, evals, cost) | B5 |
| **LangGraph** | Framework modelling an agent as an explicit graph of nodes and edges over shared, checkpointable state | B5 |
| **LangSmith** | LangChain's tracing, dataset, and evaluation platform for LLM apps and agents | B5 |
| **late interaction** | Retrieval that keeps many vectors per item and matches a query against the most relevant one (ColBERT, ColPali) | B5 |
| **Latent diffusion** | running diffusion in a compressed latent space instead of on raw pixels | B2 |
