## Glossary: D – E

| Term | Means | In |
|---|---|---|
| **Dynamic programming** | solving a known MDP exactly by repeatedly applying the Bellman equation to every state | B4 |
| **dynamic resolution** | Feeding images at (near) native resolution so the visual token count varies with image size (Qwen-VL, Pixtral) | B5 |
| **EAGLE-3** | A state-of-the-art (2026) speculative-decoding drafter that predicts from the target model's own hidden features across layers, raising acceptance | B6 |
| **early fusion** | Combining modalities at the input by putting them in one shared token vocabulary, enabling one model to read and generate both | B5 |
| **Early stopping** | halting training when validation error starts rising | B1 · B2 |
| **EchoLeak** | A 2025 CVE-class zero-click indirect-prompt-injection data-exfiltration flaw in a production AI assistant | B6 |
| **Edge deployment** | running a model on-device rather than in the cloud | B2 |
| **edge inference** | Running a model on or near the user's device (phone, browser, on-prem) for latency, privacy, offline use, and cost, at the price of capability | B6 |
| **EER (equal error rate)** | the operating point where false accepts equal false rejects | B2 |
| **effective batch size** | per-GPU batch × gradient-accumulation steps × number of GPUs; the true batch a training recipe depends on, paired with its learning rate | B6 |
| **Eigenvalue** | the factor by which a matrix stretches its eigenvector | B1 |
| **Eigenvector** | a direction a matrix only scales, without rotating | B1 |
