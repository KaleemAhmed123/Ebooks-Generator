## Glossary: M – N

| Term | Means | In |
|---|---|---|
| **multi-agent system (MAS)** | Several agents working together via division of labor, specialization, checking, or coordination | B5 |
| **Multi-head attention** | running several attention operations in parallel and combining their outputs | B3 |
| **multi-LoRA serving** | Hosting one base model in VRAM and applying many small per-tenant LoRA adapters on demand, batching different adapters together | B6 |
| **multimodal model** | One model taking more than one input type (text with images, audio, or video) and reasoning across them | B5 |
| **multimodal RAG** | Retrieval-augmented generation over a knowledge base of mixed modalities (text, images, tables, charts) | B5 |
| **multi-session handoff** | Passing distilled state (goal, progress, next steps, gotchas) from one agent run to the next | B5 |
| **MusicGen / MusicLM** | landmark text-to-music generation models | B2 |
| **Naive Bayes** | a fast classifier assuming all features are independent | B1 |
| **Named entity recognition (NER)** | finding and labeling real-world entities (people, places, orgs) in text | B3 |
| **nan** | "not-a-number"; a poisoned value that spreads through arithmetic | B1 |
| **Natural language inference (NLI)** | deciding whether a hypothesis follows from, contradicts, or is neutral to a premise | B3 |
| **NaViT (Native-resolution ViT)** | A ViT that ingests any resolution/aspect ratio directly via patch-n-pack, no tiling | B5 |
