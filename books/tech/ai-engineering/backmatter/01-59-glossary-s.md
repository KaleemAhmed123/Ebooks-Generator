## Glossary: S

| Term | Means | In |
|---|---|---|
| **SGD** | stochastic gradient descent; gradient steps on random batches | B1 |
| **SGLang** | An open-source serving framework built around RadixAttention prefix sharing and a frontend DSL for structured, branching LLM programs | B6 |
| **shadow deployment** | Mirroring live traffic to a new version without serving its output, to compare behaviour at zero user risk (read-only paths only) | B6 |
| **Show-o** | Unified model mixing autoregressive text with discrete diffusion for images in one transformer | B5 |
| **SigLIP** | CLIP variant using a pairwise sigmoid loss, training well without giant batches; a common VLM vision encoder | B5 |
| **Sigmoid** | a function squashing any number into the range 0 to 1 | B1 · B2 |
| **signature (DSPy)** | A typed declaration of a step's inputs and outputs, from which DSPy generates the prompt | B5 |
| **sim2real gap** | The performance drop when a policy trained in simulation meets real-world physics, noise, and lighting | B5 |
| **SimPO** | a reference-free DPO variant that length-normalises reward and enforces a target margin | B4 |
| **single-flight (request coalescing)** | Collapsing concurrent identical requests into one computation whose result fans out to all callers, absorbing thundering herds | B6 |
| **Singular value** | the stretch factors in an SVD, ranked by importance | B1 |
| **situational awareness** | A model behaving differently when it recognizes it is being tested or monitored | B5 |
