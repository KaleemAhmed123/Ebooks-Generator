## Glossary: T

| Term | Means | In |
|---|---|---|
| **Topic modeling** | discovering hidden themes across a document collection without labels | B3 |
| **Top-k** | decoding that samples only from the k highest-probability tokens | B4 |
| **TPOT (Time Per Output Token)** | The average per-token delay during decode; sets how fast a streamed response reads. Also ITL | B6 |
| **trace** | A tree of spans for one end-to-end request; an agent run is a trace | B5 |
| **Tracking-by-detection** | following objects by detecting each frame, then linking detections across frames | B2 |
| **Training–serving skew** | features computed differently in training and production | B1 |
| **Training set** | the data a model learns its weights from | B1 |
| **trajectory eval** | Evaluating whether an agent took the right steps and tools, not just the final outcome | B5 |
| **Transfer learning** | reusing a pretrained model's learned features on a new task | B2 |
| **Transformer** | the attention-based architecture behind modern language, vision, and speech models | B3 |
| **Transfusion** | Model running next-token prediction on text and a diffusion objective on image patches in one transformer | B5 |
| **Tree of Thoughts (ToT)** | Reasoning as a searchable tree of candidate thoughts, scored and pruned | B5 |
