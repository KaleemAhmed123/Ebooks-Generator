## Glossary: A

| Term | Means | In |
|---|---|---|
| **allocative harm** | Bias that unfairly distributes a resource or opportunity (a loan, a job screen) across groups | B6 |
| **AlphaEvolve** | DeepMind system pairing an LLM with evolutionary search and an automatic evaluator to discover improved algorithms | B5 |
| **ANN (approximate nearest neighbour)** | finding the closest vectors to a query without checking every one, trading a little accuracy for large speed gains | B4 · B6 |
| **Anomaly detection** | finding points that do not fit a learned "normal" | B1 |
| **Anti-spoofing** | detecting synthetic or faked audio to defend a voice system | B2 |
| **AnyRes** | High-resolution VLM trick: cut a large image into encoder-sized tiles, encode each plus a downsized global view, and concatenate all tokens | B5 |
| **any-resolution** | Feeding a large image as full-resolution tiles so fine detail (small text, UI) survives instead of being crushed to a fixed square | B5 |
| **API key** | a secret string that authenticates and bills your access to a model API | B1 |
| **ARIMA** | a classical statistical model for forecasting time series | B1 |
| **arithmetic intensity** | FLOPs of compute per byte moved from memory; low for decode (memory-bound), high for prefill (compute-bound). See roofline model | B6 |
| **Arrow** | an in-memory columnar data format for zero-copy sharing between tools | B1 |
| **ASL (AI Safety Level)** | Anthropic's tiered capability regime (ASL-1…5+), modelled on biosafety levels; each rung triggers stronger safeguards | B6 |
