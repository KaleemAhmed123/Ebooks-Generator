## Glossary: C – D

| Term | Means | In |
|---|---|---|
| **CrewAI** | Framework modelling agents as roles with goals, assigned tasks, run as a sequential or hierarchical crew | B5 |
| **Cross-attention** | attention where queries come from the decoder and keys/values come from the encoder | B3 |
| **Cross-encoder** | a model that reads a query and document together and outputs one relevance score; accurate but slow, used for re-ranking | B4 · B6 |
| **Cross-entropy** | the loss measuring distance between predicted and true distributions | B1 · B2 |
| **cross-modal retrieval** | Retrieving one modality with a query in another (text query returning an image, or vice versa) | B5 |
| **Cross-validation** | rotating which data fold is held out, to get a stable score | B1 |
| **CTC (connectionist temporal classification)** | an ASR method that learns audio-to-text alignment using a blank symbol | B2 |
| **CTDE (centralized training, decentralized execution)** | MARL recipe: train with a global-view critic, act on local views at run time | B5 |
| **CUDA** | NVIDIA's software layer letting frameworks use the GPU | B1 |
| **Curse of dimensionality** | in high dimensions, all points become far apart and distance loses meaning | B1 · B3 |
| **CutMix** | augmentation that pastes a patch of one image onto another and mixes their labels | B2 |
| **dangerous-capability evaluation** | Tests measuring whether a model has abilities (cyber, bio, autonomy) that trigger safeguards | B5 · B6 |
