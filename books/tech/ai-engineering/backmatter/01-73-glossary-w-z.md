## Glossary: W – Z

| Term | Means | In |
|---|---|---|
| **workflow engine** | Infrastructure (e.g. Temporal) providing durable execution and exactly-once side effects | B5 |
| **Workflows (LlamaIndex)** | LlamaIndex's event-driven low-level orchestration framework | B5 |
| **World model** | a model that predicts an environment's next state, for planning or interaction | B2 |
| **WSL** | Windows Subsystem for Linux; a real Linux environment inside Windows | B1 |
| **Xavier (Glorot) initialization** | weight initialization scaled for tanh or sigmoid layers | B2 |
| **XGBoost** | a leading gradient-boosted-trees library for tabular data | B1 |
| **XOR** | the classic non-linearly-separable problem a single perceptron cannot solve | B2 |
| **Zero-shot** | performing a task with no task-specific training examples | B2 |
| **Zero-shot classification** | labeling text with categories the model was never explicitly trained on, often via NLI | B3 · B5 |
| **ZeRO (Zero Redundancy Optimizer)** | DeepSpeed's technique of sharding optimiser state, gradients, and parameters across GPUs (stages 1–3) instead of replicating them | B6 |
| **ZOPA (zone of possible agreement)** | The range of deals both negotiating parties prefer over no deal | B5 |
