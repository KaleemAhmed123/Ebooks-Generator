## Glossary: C

| Term | Means | In |
|---|---|---|
| **Confidence interval** | a range that likely contains the true value | B1 |
| **confused deputy** | Attack where a privileged agent is tricked into misusing its own broad credentials on behalf of a low-privilege caller | B5 |
| **Confusion matrix** | the table of true/false positives and negatives | B1 |
| **consensus** | A procedure for a group of agents to agree on one result despite disagreement or bad actors | B5 |
| **Constitutional AI (CAI)** | aligning a model against written principles it uses to critique and revise its own answers, generating preference data without human labellers | B4 · B5 · B6 |
| **Constrained decoding** | masking out any next token that would violate a required output grammar, guaranteeing valid structure | B3 · B4 |
| **Container** | a running instance of a Docker image; a sealed, portable environment | B1 |
| **Context engineering** | deciding what goes into the context window, in what order and at what cost, to get the best answer per token | B4 |
| **Context length (context window)** | the maximum number of tokens a model can attend to at once | B3 |
| **Context vector** | in seq2seq, the fixed-size vector the encoder squeezes the whole input into | B3 |
| **Continuous batching** | merging many users' requests into one rolling batch at the token level so the GPU is never idle | B4 · B6 |
| **Contract Net Protocol** | Task allocation by bidding: a manager announces, agents bid, the best bid wins and executes | B5 |
