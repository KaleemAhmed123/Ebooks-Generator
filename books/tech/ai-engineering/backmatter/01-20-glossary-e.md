## Glossary: E

| Term | Means | In |
|---|---|---|
| **elicitation (MCP)** | A server asking the user for input mid-task, mediated by the host | B5 |
| **Embedding** | a vector of numbers standing in for a piece of data (a word, image) | B1 · B3 |
| **Embedding model** | a model that maps a sentence or document to a single vector tuned for similarity search | B3 |
| **emergent communication** | MARL agents inventing their own signals to coordinate when given a channel but no predefined language | B5 |
| **Emu3** | Early-fusion model that does understanding and generation of text, image, and video by pure next-token prediction over discrete tokens | B5 |
| **EnCodec** | a neural audio codec built on SoundStream's design | B2 |
| **Encoder** | the transformer half that reads input with bidirectional attention into context-rich vectors | B3 |
| **Encoder–decoder** | an architecture that reads input into features, then generates output from them | B2 · B3 |
| **Ensemble** | several models combined into a stronger predictor | B1 |
| **Entity linking** | connecting a text mention to a specific entry in a knowledge base | B3 |
| **Entropy** | a measure of surprise or uncertainty in a distribution | B1 |
| **Epoch** | one full pass of training over the entire dataset | B1 · B2 |
