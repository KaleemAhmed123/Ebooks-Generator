## Glossary: S

| Term | Means | In |
|---|---|---|
| **skill** | A packaged unit of capability (instructions plus optional scripts/resources) teaching an agent a whole task | B5 |
| **Skip connection** | a shortcut carrying signal past layers; see residual connection | B2 |
| **Skip-gram** | a word2vec variant that predicts context words from a center word | B3 |
| **sleeper agents** | Models trained with a backdoor that behaves normally except on a trigger, and that survives standard safety training (Anthropic, 2024) | B6 |
| **sleep-time compute** | Doing expensive memory consolidation between interactions so live turns stay fast | B5 |
| **Sliding-window attention** | limiting each token to attend to a local window, cutting the quadratic cost | B3 |
| **SLO (Service Level Objective)** | An explicit reliability/latency/quality target, e.g. "TTFT ≤ 500 ms at P95," against which error budgets are tracked | B6 |
| **smallest testable slice** | The smallest unit of work that produces a verifiable result; the unit to hand an agent | B5 |
| **SMOTE** | synthesizing new minority-class examples to balance data | B1 |
| **Society of Mind** | Minsky's view of intelligence as many simple interacting agents; motivates multi-agent debate | B5 |
| **Softmax** | turning raw scores into a probability distribution over classes | B1 · B2 |
| **SoundStream** | the 2021 codec that introduced residual vector quantization for audio | B2 |
