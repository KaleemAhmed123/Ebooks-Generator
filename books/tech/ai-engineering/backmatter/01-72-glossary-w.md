## Glossary: W

| Term | Means | In |
|---|---|---|
| **Weight** | a tunable number that scales an input inside a network | B2 |
| **Weight decay** | a penalty on large weights that reduces overfitting | B2 |
| **Weight initialization** | setting the starting weight values before training | B2 |
| **weight tying** | Sharing the input token-embedding matrix with the output projection in a language model, saving parameters and improving quality | B6 |
| **WER (word error rate)** | the ASR metric: the fraction of words wrong | B2 |
| **Whisper** | OpenAI's encoder–decoder ASR model, trained on 680,000 hours of audio | B2 |
| **WMDP (Weapons of Mass Destruction Proxy)** | A public benchmark of proxy hazardous knowledge (bio, chem, cyber) used to measure and unlearn dangerous capability | B6 |
| **word2vec** | the 2013 method that learns word embeddings from context via skip-gram or CBOW | B3 |
| **Word embedding** | a dense vector representing a single word | B3 |
| **WordPiece** | a subword tokenizer (BERT) that merges pairs by corpus likelihood rather than raw frequency | B3 |
| **workbench** | Everything around the model — instructions, tools, context, feedback, scope — that determines whether it succeeds | B5 |
| **workflow** | A system where you code the steps and the model fills blanks, as opposed to an agent choosing the steps | B5 |
