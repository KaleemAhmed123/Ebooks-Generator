## Glossary: S

| Term | Means | In |
|---|---|---|
| **SAM (Segment Anything Model)** | Meta's promptable segmentation foundation model; SAM 3 (2025) adds concept segmentation | B2 |
| **sandbox** | An enforced environment (container, VM) limiting what code can do regardless of permission logic | B5 |
| **SARSA** | an on-policy TD control method that updates Q using the action actually taken next; contrast Q-learning | B4 |
| **scalable oversight** | Techniques for supervising a model more capable than its supervisors (weak-to-strong, debate, task decomposition, AI-assisted evaluation) | B6 |
| **Scaled dot-product attention** | attention scores divided by √d_k before softmax to keep gradients healthy | B3 |
| **Scaling laws** | the empirical rule that loss falls predictably as parameters, data, and compute grow | B3 |
| **scope contract** | An explicit, enforced statement of what an agent may read, write, and call | B5 |
| **sectioning** | Parallelization flavor that splits a task into independent sub-parts done concurrently | B5 |
| **Self-attention** | attention where queries, keys, and values all come from the same sequence | B3 |
| **self-play** | An agent improving by training against copies of itself, creating an automatic difficulty curriculum | B5 |
| **self-refine** | Producing an answer, critiquing it, and revising over a few rounds to raise quality | B5 |
| **Self-supervised learning (SSL)** | learning from unlabelled data via a task invented from the data itself | B2 |
