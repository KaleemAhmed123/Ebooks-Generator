## Glossary: D

| Term | Means | In |
|---|---|---|
| **Diffusion model** | a generator that creates data by repeatedly removing noise, learned in reverse | B2 |
| **Diffusion transformer (DiT)** | a diffusion model whose denoiser is a transformer over patches | B2 |
| **Dimension** | the number of entries in a vector | B1 |
| **Dimensionality reduction** | compressing data into fewer, more informative numbers | B1 |
| **disaggregated serving** | Running prefill and decode on separate GPU pools, each tuned to its phase, transferring the KV cache between them | B6 |
| **Discount (γ)** | a factor between 0 and 1 that shrinks the value of future rewards so sooner is worth more than later | B4 |
| **Discriminative model** | a model that learns the boundary between classes, `P(label | input)`; contrast generative | B4 |
| **Discriminator** | the GAN network that judges images as real or fake | B2 |
| **Distillation** | training a small student model to copy a large teacher model | B2 |
| **Distributional hypothesis** | the idea that words appearing in similar contexts have similar meanings | B3 |
| **Docker** | a tool that packages code and its whole environment into portable containers | B1 |
| **Dockerfile** | the recipe that builds a Docker image | B1 |
