## Glossary: V

| Term | Means | In |
|---|---|---|
| **venv** | Python's built-in virtual environment tool | B1 |
| **verbal RL** | Reinforcement via language feedback (a written reflection) rather than weight updates; Reflexion's principle | B5 |
| **verification gate** | A hard checkpoint a result must pass before an agent may proceed | B5 |
| **Vickrey auction** | Second-price sealed-bid auction where bidding your true value is optimal | B5 |
| **virtual context** | Faking an unbounded context by paging facts between the window and external storage (MemGPT) | B5 |
| **vision-language model (VLM)** | A model taking images and text in and producing text out | B5 |
| **Vision Transformer (ViT)** | Encoder that splits an image into fixed patches, embeds each as a token, and runs a standard transformer; the eye in most VLMs | B5 |
| **visual instruction tuning** | Training a VLM on (image, instruction, answer) data, often generated by prompting a text LLM with image annotations (LLaVA) | B5 |
| **ViT (vision transformer)** | a transformer that works on image patches instead of convolutions | B2 |
| **VLA (vision-language-action model)** | A VLM that outputs robot actions instead of text, via action tokenization | B5 |
| **vLLM** | The default open-source inference engine, built on PagedAttention and continuous batching, exposing an OpenAI-compatible server | B6 |
| **VLM (vision-language model)** | a model that takes an image and text and replies in text | B2 · B5 |
