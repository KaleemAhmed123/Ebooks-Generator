## Glossary: M

| Term | Means | In |
|---|---|---|
| **mem0** | Open memory layer with fact extraction, new/update/conflict reconciliation, and hybrid vector+graph storage | B5 |
| **MemGPT (Letta)** | System applying virtual-memory paging to LLMs; the agent manages its own context via memory tools | B5 |
| **memory blocks** | Structured, rewritten memory units (persona, human, task) an agent maintains instead of a raw transcript | B5 |
| **mesa-optimization** | When training an optimiser produces a model that is itself an optimiser with its own internal goal, possibly diverging from the training objective (Hubinger et al., 2019) | B6 |
| **METR** | Independent evaluator of frontier models' autonomous capability; originator of the task-horizon metric | B5 · B6 |
| **Metric learning** | training embeddings so that distance reflects similarity | B2 |
| **MIG (Multi-Instance GPU)** | Partitioning one datacenter GPU into hardware-isolated slices, each with its own memory and compute, to pack multiple small models onto one card | B6 |
| **Mimi** | the streaming neural audio codec inside Moshi | B2 |
| **Mixture-of-Agents (MoA)** | Layered aggregation where agents answer, an aggregator synthesises, repeated to refine | B5 |
| **Mixture of experts (MoE)** | replacing one feed-forward block with many, activating only a few per token to grow capacity cheaply | B3 |
| **Mixup** | augmentation that blends two images and their labels | B2 |
| **MLflow** | a tool for tracking experiments and their results | B1 |
