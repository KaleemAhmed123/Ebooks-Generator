## Glossary: P

| Term | Means | In |
|---|---|---|
| **pointing (VLM)** | A VLM emitting pixel coordinates for an object or UI element, enabling action and grounding | B5 |
| **Policy (π)** | the agent's behaviour: the probability of each action given the state; what you deploy | B4 |
| **Policy gradient** | an RL method that adjusts a policy's parameters directly to make high-return actions more likely | B4 |
| **Pooling** | a fixed downsampling that shrinks feature maps, e.g. max pooling | B2 |
| **POPE (Polling-based Object Probing Evaluation)** | Hallucination benchmark asking yes/no questions about present and absent objects | B5 |
| **Positional encoding** | information added to token embeddings so the model knows word order | B3 |
| **POS tagging** | labeling each word with its part of speech (noun, verb, adjective) | B3 |
| **Posterior** | the updated belief after seeing evidence | B1 |
| **PPO (proximal policy optimization)** | a stable policy-gradient algorithm that clips how far each update can move the policy; the RLHF workhorse | B4 |
| **Precision** | of the cases flagged positive, the fraction that were right | B1 |
| **Preference pair** | a prompt with two answers, one marked chosen and one rejected, used to train alignment | B4 |
| **Prefill** | the generation phase that processes the whole prompt in one parallel pass; compute-bound | B4 · B6 |
