## Glossary: B

| Term | Means | In |
|---|---|---|
| **BLEU** | a translation metric scoring word-sequence overlap with a human reference | B3 |
| **BLIP-2** | VLM that bridges a frozen vision encoder and frozen LLM with a small trainable Q-Former | B5 |
| **block table** | The per-request map from logical token positions to physical KV-cache blocks in PagedAttention, the analogue of a virtual-memory page table | B6 |
| **BM25** | a refined keyword-search ranking that extends TF-IDF with document length and term-saturation adjustments | B3 · B4 |
| **Boosting** | training models in sequence, each fixing the previous ones' mistakes; cuts bias | B1 |
| **bounded self-improvement** | An improvement loop capped by an external verifier; the regime all shipping systems use | B5 |
| **Bounding box** | a rectangle marking where an object sits in an image | B2 |
| **BPE (Byte-Pair Encoding)** | a subword tokenizer that repeatedly merges the most frequent adjacent pair of symbols | B3 |
| **Bradley-Terry model** | the statistical model behind reward training: fit scores so a preferred item outranks a rejected one | B4 |
| **Branch** | a parallel line of work in git that leaves the main line untouched | B1 |
| **Broadcasting** | automatically stretching a smaller tensor to match a larger one's shape | B1 |
| **browser agent** | Computer-use agent specialised to the web: navigate, click, fill forms, extract data, via the DOM or screenshots | B5 |
