## Glossary: J – K

| Term | Means | In |
|---|---|---|
| **JSON-RPC** | Lightweight remote-procedure-call standard (request, response, notification) that MCP messages use | B5 |
| **JSON-RPC 2.0** | Simple request/response format over JSON; MCP's message layer | B5 |
| **JSON Schema** | Standard for describing the shape of JSON data; used to define tool input parameters | B5 |
| **judge (LLM-as-judge)** | A model scoring outputs against a rubric, used to pick the best candidate or grade evals | B5 |
| **Kaiming (He) initialization** | weight initialization scaled for ReLU layers | B2 |
| **KEDA** | A Kubernetes event-driven autoscaler that scales pods on custom metrics such as queue depth, used for GPU autoscaling | B6 |
| **Kernel (filter)** | the small weight grid slid across an input in a convolution | B2 |
| **Kernel (Jupyter)** | the process holding a notebook's shared variable state | B1 |
| **Kernel trick** | measuring similarity as if data were lifted into a higher dimension | B1 |
| **kill switch** | An external, always-reachable control that stops an agent and revokes its access immediately | B5 |
| **KL divergence** | an asymmetric measure of how different two distributions are | B1 |
| **KL penalty** | a term that subtracts reward when the policy drifts too far from a trusted reference model; the RLHF safety leash | B4 |
