## GAIA

- **GAIA** (General AI Assistants) tests whether an agent can answer **real-world questions that require tools and multi-step reasoning** — the kind a capable human assistant handles by browsing, computing, and reading files, not by recalling facts. **[VERIFY current scores]**

- **What a GAIA question looks like:** something conceptually simple for a human but requiring several tool-using steps for a machine — e.g. "find a specific number in a linked spreadsheet, cross-reference it with a fact from a web page, and compute a result." The answer is a single, **checkable** value (so scoring is objective), but reaching it needs web browsing, file handling, and reasoning chained together.
- **Why it is a good assistant benchmark:** it deliberately targets tasks that are **easy for humans, hard for AI** — resisting the pattern where benchmarks reward narrow model skills. Success requires *general* competence: using multiple tools, handling different file types (multimodal, Module 12), and not losing the thread across steps. It measures the "capable generalist assistant" ideal directly.
- GAIA has difficulty **levels** (more steps/tools = harder), so it tracks progress from simple two-step tasks to long multi-tool chains. **[VERIFY]**

:::interview
"What capability does GAIA test that a knowledge benchmark doesn't?"

General, multi-step, tool-using competence. GAIA questions are easy for a person but need an agent to chain several real actions — browse the web, open and read a file (often multimodal), compute — to reach a single checkable answer. It's designed to be easy for humans and hard for AI, so it resists rewarding narrow skills and instead measures whether an agent can act as a capable generalist assistant: pick the right tools, handle varied inputs, and hold the thread across steps without drifting. Objective scoring (one exact answer) makes it a clean signal.
:::
