## LATS: search meets acting

- **LATS** (Language Agent Tree Search, Zhou et al., 2023) unifies the module's ideas: it runs **Monte Carlo Tree Search (MCTS)** — the algorithm behind game-playing AI (Booklet 4's RL) — over an agent that *acts with tools*, and folds in **reflection**. It is Tree of Thoughts plus real actions plus learning from failure.

- **The MCTS loop:** *select* a promising node (balancing exploring new branches vs exploiting known-good ones), *expand* it by taking an action (a tool call, then observe), *evaluate* the resulting state (model score + any real feedback), and *backpropagate* that value up the tree so future selections are smarter. Reflections on failed branches feed back as lessons.
- **What it buys:** the strongest results on hard agentic benchmarks (reasoning + acting), because it systematically searches the *action* space, not just the reasoning space — it can try a tool, see it fail, back up, and try another approach with memory of what didn't work.
- **The cost is extreme:** many trajectories, each with tool calls and evaluations — the most expensive pattern here by far. LATS is a research-grade tool for maximum capability on hard problems, rarely justified in latency-sensitive production.

:::note
LATS is the capstone of this cluster: it composes tree search (ToT), acting (ReAct), and reflection into one method, guided by the MCTS algorithm that powered game-playing agents. Know it as the "throw maximum compute at a hard agentic task" pattern, and as evidence that classic search algorithms (Booklet 4) transfer directly to LLM agents — the model is just the policy and value function.
:::
