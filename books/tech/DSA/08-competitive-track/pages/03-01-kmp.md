## Knuth-Morris-Pratt (KMP) 🔴

String matching in competitive programming usually means finding all occurrences of a Pattern P inside a Text T.
The naive approach (sliding the pattern one character at a time) takes O(|T| times |P|). If both strings are length 10⁵, this is 10¹⁰ operations and will TLE.

KMP does it in strictly O(|T| + |P|) time by exploiting the internal symmetries of the Pattern.

### The LPS Array

The magic of KMP is the LPS array (Longest Proper Prefix which is also Suffix).
For the pattern P, `LPS[i]` stores the length of the longest proper prefix of P[0 dots i] that is also a suffix of P[0 dots i].

Example: `P = "ABABCABAB"`
- `LPS = [0, 0, 1, 2, 0, 1, 2, 3, 4]`
- Look at index 3: `"ABAB"`. The prefix `"AB"` matches the suffix `"AB"`. Length is 2. So `LPS[3] = 2`.

**Why this matters:** When searching the Text, if we match the first 3 characters `"ABA"` but fail on the 4th, we *know* we don't have to start over from index 1. We know `"A"` (length 1) is a valid prefix that we just saw. We can safely skip ahead!

### Implementation (C++)

```cpp
// 1. Build the LPS Array
vector<int> buildLPS(string pattern) {
    int m = pattern.length();
    vector<int> lps(m, 0);
    int len = 0; // Length of the previous longest prefix suffix
    int i = 1;
    
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len != 0) {
                // The tricky part: Fall back to the previous known prefix!
                len = lps[len - 1];
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    return lps;
}

// 2. Search Text
vector<int> kmpSearch(string text, string pattern) {
    vector<int> matches;
    int n = text.length();
    int m = pattern.length();
    if (m == 0) return matches;
    
    vector<int> lps = buildLPS(pattern);
    int i = 0; // index for text
    int j = 0; // index for pattern
    
    while (i < n) {
        if (pattern[j] == text[i]) {
            j++;
            i++;
        }
        if (j == m) {
            matches.push_back(i - j);
            j = lps[j - 1]; // Found a match, reset j using LPS
        } else if (i < n && pattern[j] != text[i]) {
            if (j != 0) {
                j = lps[j - 1]; // Mismatch, fall back safely
            } else {
                i++;
            }
        }
    }
    return matches;
}
```

### The Magic KMP Application

Finding the shortest repeating substring that makes up a string S (e.g., `"ABABAB"` is made of `"AB"`).
Compute `LPS` for the whole string.
If `N % (N - LPS[N-1]) == 0`, the shortest repeating substring has length `N - LPS[N-1]`.
