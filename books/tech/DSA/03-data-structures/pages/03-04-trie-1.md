## Trie (Prefix Tree) <span class="lv lv2"></span>

- **What it is:** An N-ary tree where each node represents a single character of a string
- **The Contract:** O(L) time to insert or search for a word, where L is the length of the word (independent of how many millions of words are in the dictionary)
- **Why it works:** It acts as a **Prefix Prefix-Sharer**. If you insert "apple" and "app", they share the exact same `a -> p -> p` nodes. It perfectly maps the hierarchical nature of language

### The Structure

Unlike a Binary Tree which has `left` and `right` pointers, a Trie node has a Hash Map (or a 26-element array) of children, mapping a character to the next node. Crucially, the node itself does *not* store its character; the *edge* leading to the node implies the character.

```ts
class TrieNode {
  // Using a Map allows for any character. 
  // For lowercase English only, a new Array(26) is faster.
  children: Map<string, TrieNode> = new Map();
  isWord: boolean = false; // The termination flag
}

class Trie {
  root: TrieNode = new TrieNode();

  insert(word: string) {
    let curr = this.root;
    for (const char of word) {
      if (!curr.children.has(char)) {
        curr.children.set(char, new TrieNode());
      }
      curr = curr.children.get(char)!;
    }
    curr.isWord = true; // Mark the end of the word
  }
}
```
