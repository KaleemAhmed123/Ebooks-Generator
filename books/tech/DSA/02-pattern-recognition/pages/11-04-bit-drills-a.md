## Recognition drills after Chapter 11 <span class="lv lv1"></span>

Name the page before you turn over. Two come from earlier chapters.

1. Count the bit positions where two integers differ.
2. Every value appears three times except one; find that one in O(1) extra space.
3. Decide whether a string of `()[]{}` closes every bracket in the right order.
4. An array was encoded as `e[i] = a[i] XOR a[i + 1]`; given `e` and `a[0]`, rebuild `a`.
5. Return the number of 1 bits in every integer from 0 to n, in O(n) total.
6. Find the first index where the sum of everything to its left equals the sum of everything to its right.
7. Return the bitwise AND of every integer in the range `[left, right]`.
8. Exactly two values appear once and every other value twice; return the two.
9. The numbers 1..n, except one value was overwritten by a copy of another; return the copy and the lost value.
10. Return the unsigned 32-bit integer whose bits are the input's bits in reverse order.
11. Given `p[i] = a[0] XOR … XOR a[i]` for every i, rebuild `a`.
12. Sum the number of differing bit positions over every pair of numbers in an array.
