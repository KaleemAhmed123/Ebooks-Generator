## Prefix Tree (Trie) <span class="lv lv1"></span>

- **What:** a **trie** stores strings by their shared prefixes. Each edge is one character, each path a prefix, and a flag marks where a real word ends. Lookup and prefix tests cost O(word length), whatever the dictionary size
- **Spot it:** "starts with", "autocomplete", "prefix", "dictionary of words", "search word with `.` wildcards", "longest word built from others"
- **Why:** branching on the next character walks a prefix once and shares it across every word that has it. Building n words of total length L is O(L); a query is O(len), never O(n · len) as scanning the whole list would be

```ts
// Implement Trie (LeetCode 208)
class TrieNode { children: Record<string, TrieNode> = {}; end = false; }
class Trie {
  root = new TrieNode();
  insert(word: string): void {
    let node = this.root;
    for (const ch of word) node = node.children[ch] ??= new TrieNode(); // create on the way
    node.end = true;                                     // mark a real word ends here
  }
  private walk(s: string): TrieNode | null {
    let node = this.root;
    for (const ch of s) { const nxt = node.children[ch]; if (!nxt) return null; node = nxt; }
    return node;                                         // node at the end of s, or null
  }
  search(word: string): boolean { const n = this.walk(word); return !!n && n.end; }
  startsWith(prefix: string): boolean { return this.walk(prefix) !== null; }
}
```

- **Watch out:** `search` and `startsWith` differ only by the `end` flag — a stored "apple" makes `startsWith("app")` true but `search("app")` false until "app" is inserted. For `.` wildcard search (LeetCode 211), a `.` forks into a DFS over all children at that level
