## Recognition drills after Chapter 3 <span class="lv lv1"></span>

Name the page before you turn over. Two come from Chapter 2.

1. Over all index triples i < j < k, maximise (a[i] − a[j]) · a[k]; return 0 if every triple scores below 0.
2. You may flip at most k zeros to ones; return the longest run of ones.
3. Each person is alive from a birth year up to, not including, a death year; return the earliest year with the most people alive.
4. Return the longest substring in which every vowel appears an even number of times.
5. Return the largest absolute value of any subarray's sum.
6. Count the split points where the left part's sum is at least the right part's, with at least one element on the right.
7. Remove the shortest run of positive values, never the whole array, so that the rest sums to a multiple of p.
8. For every index, return the product of all the other values, without using division.
9. Count the runs of positive integers whose product stays strictly below k.
10. Return every day preceded by t days of non-increasing values and followed by t days of non-decreasing values.
11. Maximise the sum of a non-empty subarray from which you may delete at most one element.
12. A car with a fixed number of seats picks up and drops off groups at given stops; can it serve every trip?
