:::interview
"Why a trie instead of a hash set of words?"

A hash set answers exact membership in O(word), but cannot answer "is any stored word a prefix of this" or "how many words start with this" without scanning everything. A trie shares prefixes, so prefix queries are O(prefix length) and prefix-structured searches (wildcards, word-search pruning) walk only the relevant branch.
:::
