## Recognition drills after Chapter 5 <span class="lv lv1"></span>

Name the page for each statement before turning over. Decide table, graph or DP first (05-00), then the move. Answers overleaf.

1. An m×n grid is shifted k times. Each shift moves every value one cell right, the last value of a row to the start of the next row, and the bottom-right value to the top-left. Return the grid
2. In a 0/1 grid, return the largest number of 1-cells joined through up, down, left and right neighbours
3. Rows are sorted left to right and columns top to bottom. Say whether a target value is present
4. Count the submatrices that contain the top-left cell and have a sum of at most k
5. Turn an n×n image 90° clockwise without allocating another matrix
6. Return true when every top-left to bottom-right diagonal holds a single repeated value
7. Wherever a cell is 0, its whole row and column become 0. Do it in place
8. Walk from the top-left to the bottom-right of a grid of non-negative numbers, moving only right or down, and minimise the sum collected
9. Each row is sorted, and each row's first value is greater than the previous row's last. Find a target in O(log(m·n))
10. An n×n grid should hold 1 to n² once each, but one value appears twice and another is missing. Return both
11. Given two n×n 0/1 matrices, can the first become the second by turning it in steps of 90°?
12. Every cell of a board lives or dies by counting its eight neighbours, and all cells change at the same moment. Update the board in place
