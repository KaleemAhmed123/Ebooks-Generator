## Checkpoint: which page? (Chapters 2–4) <span class="lv lv1"></span>

Ten statements from every chapter so far, mixed on purpose. For each, write the page ID before turning over. No tags, no titles: this is how the problem arrives in an interview.

1. Largest total of any contiguous run; values may be negative.
2. Every start index in s where some rearrangement of p begins.
3. Largest product of any contiguous run; values may be negative or zero.
4. Two values in an unsorted array add to a target; return their original positions.
5. Count contiguous runs whose total equals k; values may be negative.
6. One buy, then one later sell: the best profit.
7. Longest stretch of a string with no repeated character.
8. An array holds only 0, 1 and 2; sort it in place in one pass.
9. Return the value that fills more than half the array, O(1) extra space.
10. Every distinct triple of values that sums to zero.
