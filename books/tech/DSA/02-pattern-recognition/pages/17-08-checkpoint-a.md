## Checkpoint: which page? (Chapters 2–17) <span class="lv lv1"></span>

Ten statements from every chapter so far, mixed on purpose. For each, write the page ID before turning over. No tags, no titles: this is how the problem arrives in an interview.

1. Median of all numbers seen so far, after every insert.
2. Can every course be finished, given pairs "a needs b first"?
3. Longest strictly increasing subsequence.
4. The k-th largest value in an unsorted array.
5. Smash the two heaviest stones until at most one is left.
6. Can the array split into two parts of equal sum?
7. Largest sum of any path, starting and ending anywhere in a binary tree.
8. Merge k sorted linked lists into one.
9. Fewest coins that make an amount, unlimited coins of each value.
10. Two numbers stored as linked lists, least significant digit first; return their sum.
