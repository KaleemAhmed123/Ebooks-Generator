## Recognition drills after Chapter 9 <span class="lv lv1"></span>

Name the page for each statement, and say what is searched (an index, a value, an answer) and the test that flips once. Answers overleaf.

1. A matrix is sorted in non-increasing order along every row and every column. Count its negative numbers
2. Piles of bananas must be finished within h hours, one pile per hour at a fixed rate. Find the slowest rate that works
3. A sorted array holds 1 and primes. Among all fractions `a[i] / a[j]` with `i < j`, return the k-th smallest
4. A sorted array of distinct values was cut and its two parts swapped. Find a target's index in O(log n)
5. Piles of candy may be split but not merged. Give k children the same amount each, every child from a single pile; maximise that amount
6. Changing `s[i]` to `t[i]` costs `|s[i] − t[i]|`. Find the longest substring that can be changed within a budget
7. Return the k-th smallest absolute difference over all pairs of an array
8. In a matrix with no two adjacent cells equal, return any cell greater than its four neighbours, in O(m log n)
9. Return the integer square root of x, rounded down, without an exponent operator
10. Place c cows in n stalls at given positions so that the closest two are as far apart as possible
11. A sorted array of distinct values was rotated. Return its smallest element in O(log n)
12. Flower i blooms on day `bloom[i]`. A bouquet takes k adjacent bloomed flowers. Find the first day on which m bouquets can be made
13. Every row and every column of an n×n matrix is sorted. Return its k-th smallest element using less than O(n²) memory
