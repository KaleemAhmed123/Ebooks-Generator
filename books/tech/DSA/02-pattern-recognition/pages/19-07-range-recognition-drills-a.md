## Recognition drills after Chapter 19 <span class="lv lv2"></span>

Decide whether the data changes, then whether the operation can be undone or overlapped (19-01). Answers overleaf.

1. Insert numbers one at a time into a sorted container; each insertion costs the smaller of "how many are strictly less" and "how many are strictly greater". Values ≤ 10⁵. Return the total cost.
2. For every cell of a matrix, return the sum of all cells within k rows and k columns of it.
3. Bookings `[start, end)` arrive one at a time, at most 400. After each, report the largest number of bookings that overlap at one moment.
4. Find the longest strictly increasing subsequence whose neighbours differ by at most k; n and values up to 10⁵.
5. A fixed array and up to 10⁴ questions "sum of positions l to r".
6. Apply many operations "shift the letters from l to r one step forward (or backward)", then print the string once.
7. Count pairs `i < j` with `a[i] − a[j] ≤ b[i] − b[j] + diff`; n up to 10⁵, values within ±10⁴.
8. A fixed array of 10⁵ numbers and many questions "minimum on l to r".
9. Values lie between 1 and 100. For each query `l..r`, return the smallest non-zero difference between two values in that stretch.
10. An array receives point assignments mixed with questions "sum of l to r".
11. Many queries ask for the XOR of `a[l..r]`.
