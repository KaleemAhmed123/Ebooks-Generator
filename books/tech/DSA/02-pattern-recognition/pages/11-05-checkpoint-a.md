## Checkpoint: which page? (Chapters 2–11) <span class="lv lv1"></span>

Ten statements from every chapter so far, mixed on purpose. For each, write the page ID before turning over. No tags, no titles: this is how the problem arrives in an interview.

1. A cache of fixed size that evicts the least recently used key, O(1) per call.
2. Add two integers without using + or −.
3. Remove from either end until exactly x is removed; fewest removals.
4. For each day, how many days until a warmer one.
5. How many 1 bits in a 32-bit integer.
6. Largest total of a contiguous run in a circular array.
7. Move every zero to the end, keeping the other values in order, in place.
8. Every value appears twice except one; find it in O(1) space.
9. Smallest daily capacity that ships every package, in order, within D days.
10. Shortest contiguous run with total at least target; all values positive.
