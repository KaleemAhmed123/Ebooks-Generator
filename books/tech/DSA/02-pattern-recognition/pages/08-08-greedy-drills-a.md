## Recognition drills after Chapter 8 <span class="lv lv1"></span>

Name the page for each statement, and say in one phrase why the move is safe. If no reason comes, assume it is not greedy. Answers overleaf.

1. Given a sorted array and n, add the fewest numbers so that every value from 1 to n is the sum of some elements
2. Split an even number of players into pairs whose skill totals are all equal; return the sum of each pair's product, or −1
3. Each index says how far forward a jump from it may go at most. Find the fewest jumps to the last index, which is reachable
4. 2n people each have a price to fly to city A and to city B. Exactly n go to each. Minimise the total
5. Pairs `[a, b]` with `a < b`; `[c, d]` may follow `[a, b]` when `b < c`. Find the longest chain, taking pairs in any order
6. Stations sit on a loop. Each gives some fuel, and each leg to the next costs some. Which start completes the loop?
7. Two players take turns removing stones; each values every stone differently, and both play optimally. Who wins?
8. Jobs each take one unit of time and have a deadline and a profit. Maximise the profit
9. Jobs have a start, an end and a profit; a job may start when another ends. Choose non-overlapping jobs for the most profit
10. Clips `[start, end]` may be cut freely. Find the fewest clips that cover `[0, time]`
11. Each boat carries at most two people within a weight limit. Find the fewest boats
12. Start with a positive value and add the array left to right. Find the smallest start that keeps every running total at 1 or more
