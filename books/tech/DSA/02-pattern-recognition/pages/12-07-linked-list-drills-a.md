## Recognition drills after Chapter 12 <span class="lv lv1"></span>

Name the page before you turn over. Two come from earlier chapters.

1. Swap the values of the k-th node from the start and the k-th node from the end.
2. Return the node where a list's loop begins, or null, without extra memory.
3. Remove every occurrence of a value from an array in place and return how many values remain.
4. Split a list into groups of sizes 1, 2, 3, …; reverse every group whose actual length is even.
5. Move every node with a value below x before the others, keeping the original order on each side.
6. Deep-copy a list whose nodes also point to any node of the list, or to null.
7. For each node, report the value of the first later node with a strictly larger value, or 0.
8. Swap every two adjacent nodes, moving nodes rather than values.
9. Sort a list by taking nodes one at a time and inserting each into the sorted part.
10. Remove the n-th node from the end in one pass.
11. A list holds a number, most significant digit first; return the list for twice that number.
12. Rearrange nodes L0, L1, …, Ln into L0, Ln, L1, Ln−1, … in place.
