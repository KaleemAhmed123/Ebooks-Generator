## Checkpoint: which page? (Chapters 2–8) <span class="lv lv1"></span>

Ten statements from every chapter so far, mixed on purpose. For each, write the page ID before turning over. No tags, no titles: this is how the problem arrives in an interview.

1. Return a matrix's values in clockwise spiral order.
2. Insert an interval into a sorted list of non-overlapping intervals, merging as needed.
3. Shortest part of s that contains every character of t, with counts.
4. Keep each value at most twice in a sorted array, in place; return the new length.
5. Longest substring that reads the same in both directions.
6. For each value, how many smaller values sit to its right.
7. Do two strings use the same letters with the same counts?
8. Check a 9 × 9 board: no digit repeats in any row, column or 3 × 3 box.
9. Order the numbers so that their concatenation is as large as possible.
10. Does the string read the same both ways once case and punctuation are ignored?
