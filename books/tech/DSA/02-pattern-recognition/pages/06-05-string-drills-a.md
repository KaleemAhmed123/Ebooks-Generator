## Recognition drills after Chapter 6 <span class="lv lv1"></span>

Name the page for each statement before turning over. Ask first whether order matters, then whether the string is contiguous. Answers overleaf.

1. Can the second string be reached from the first by repeatedly moving its first character to the end?
2. Count the contiguous pieces of a string that read the same forwards and backwards
3. In a string of digits, return the length of the longest substring whose characters could be reordered into a palindrome
4. Can every character of s be replaced, consistently, to give t, with no two characters turning into the same one?
5. Does some reordering of the short string appear as a contiguous piece of the long one?
6. Return the fewest characters to insert, anywhere, so the string reads the same both ways
7. Group the words that use the same letters the same number of times
8. Two words are "close" if one reaches the other by swapping positions freely and by swapping the roles of two letters that both occur (every a becomes b, every b becomes a). Decide
9. Delete at most one character. Can the string then read the same both ways?
10. Two words of equal length: find the fewest single-letter replacements in the second so that it uses exactly the first's letters, in any order
11. From a word list, return every word that is a letter-for-letter relabelling of a pattern, with no two letters sharing a label
