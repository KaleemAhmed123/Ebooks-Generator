## Glossary (I–K)

- **Idempotent Operation:** An operation with op(x, x) = x, such as min, max and gcd; overlapping ranges do no harm.
- **Implicit Graph:** A graph not explicitly given as nodes/edges, but derived from the rules of the problem (e.g., a 2D grid where adjacent cells are edges).
- **In-degree:** The number of edges entering a vertex.
- **Interval (Partition) DP:** A DP whose state is a range (i, j), solved by trying every split point k inside it.
- **Invariant:** A quantity every allowed operation leaves unchanged.
- **Inversion:** A pair i < j with a[i] > a[j].
- **Kadane's Algorithm:** Best subarray sum ending at each index: extend the previous best or restart at the current value.
- **Kahn's Algorithm:** A topological sort that repeatedly removes vertices whose in-degree is zero.
- **Kruskal's Algorithm:** A Minimum Spanning Tree algorithm that sorts all edges and greedily adds them if they don't form a cycle (using Union-Find).
