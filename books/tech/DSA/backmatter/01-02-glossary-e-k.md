## Glossary (E–K)

- **Edit Distance:** A classic DP problem calculating the minimum number of insertions, deletions, and replacements to convert one string into another.
- **Exhaustive Search:** Another term for brute force, generating every possible candidate solution to guarantee finding the optimal one.
- **Fenwick Tree (Binary Indexed Tree):** A tree structure hidden inside an array that updates elements and calculates prefix sums in O(log N) time.
- **Greedy Algorithm:** Making the locally optimal choice at every step with the assumption that it will lead to the global optimum.
- **Hash Map:** A data structure providing O(1) average time for key-value insertions and lookups by passing keys through a hashing function.
- **Hash Set:** A Hash Map that only stores keys (no values), providing O(1) membership checking.
- **Heap:** A Complete Binary Tree (typically stored in an array) where the parent is always smaller/larger than its children, giving O(log N) access to the extremum.
- **Heap Sort:** An unstable, in-place O(N log N) sorting algorithm that builds a max-heap and repeatedly extracts the root.
- **Implicit Graph:** A graph not explicitly given as nodes/edges, but derived from the rules of the problem (e.g., a 2D grid where adjacent cells are edges).
- **Kruskal's Algorithm:** A Minimum Spanning Tree algorithm that sorts all edges and greedily adds them if they don't form a cycle (using Union-Find).
