## Glossary (N–P)

- **Ordered Set:** A sorted container that finds any value's predecessor and successor in O(log n).
- **Partition DP:** A DP that finds the minimum (or maximum) number of cuts to split a sequence so that every piece satisfies a given property.
- **Pareto Frontier:** The candidates that no other candidate beats on every dimension.
- **Pattern (Pattern Recognition):** One mechanism, meaning the state kept and the invariant that makes it correct, together with every question it answers.
- **Prefix Sum:** A precomputed array of running totals, so any range sum is the difference of two entries in O(1).
- **Prim's Algorithm:** A Minimum Spanning Tree algorithm that grows a single tree by repeatedly adding the cheapest edge to an unvisited node via a Min-Heap.
- **Priority Queue:** An abstract data type where elements are dequeued in order of their priority, typically implemented using a Heap.
- **Popcount:** The number of set bits (1-bits) in an integer; computed by repeatedly clearing the lowest set bit with `n & (n - 1)`.
- **Pruning:** Abandoning a recursive branch in Backtracking early because it is mathematically guaranteed to not yield a valid or optimal solution.
