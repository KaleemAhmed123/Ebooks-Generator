## Redis

```yaml
redis:
  image: redis:8-alpine
  command:
    - "redis-server"
    - "--requirepass"
    - "${REDIS_PASSWORD:?required}"
    - "--maxmemory"
    - "192mb"
    - "--maxmemory-policy"
    - "allkeys-lru"
    - "--appendonly"
    - "no"
  volumes:
    - redisdata:/data
  healthcheck:
    test: ["CMD-SHELL", "redis-cli -a $$REDIS_PASSWORD ping | grep PONG"]
    interval: 10s
    retries: 5
  deploy:
    resources:
      limits: { memory: 256M }
  networks: [internal]
  restart: unless-stopped
```

- `$$` in a Compose health check escapes the dollar sign so Compose passes it through to the shell rather than substituting it
