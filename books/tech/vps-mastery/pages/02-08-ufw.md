## The firewall

- **UFW** (Uncomplicated Firewall) is a front end over the kernel packet filter. It decides which ports accept connections from outside
- Default policy first, then the allowances, then enable. In this order

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing

sudo ufw allow OpenSSH        # port 22. Do not skip this line
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

sudo ufw enable
```

- `ufw enable` prompts because it can break the current session. It cannot, if `OpenSSH` was allowed first

```bash
sudo ufw status verbose
```

```text
Status: active
Default: deny (incoming), allow (outgoing)

To                   Action      From
--                   ------      ----
22/tcp (OpenSSH)     ALLOW IN    Anywhere
80/tcp               ALLOW IN    Anywhere
443/tcp              ALLOW IN    Anywhere
```

### Restricting a port to one address

```bash
sudo ufw allow from 203.0.113.55 to any port 22 proto tcp
```

### The warning that matters

- **This firewall does not protect published Docker ports.** The next page explains why, and it is the single most common way a database ends up readable from the internet
