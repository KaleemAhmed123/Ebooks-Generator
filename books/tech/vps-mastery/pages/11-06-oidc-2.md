### What it cannot replace

- A plain VPS has no identity provider to exchange a token with. SSH deploys still need a key
- Limit that key instead: a dedicated deploy user, a command restriction in `authorized_keys`, and no shell

```text
command="/srv/app/deploy.sh",no-agent-forwarding,no-port-forwarding,no-pty ssh-ed25519 AAAA...
```

- That key can run one script and nothing else. Stolen, it can trigger a deploy, not open a shell
