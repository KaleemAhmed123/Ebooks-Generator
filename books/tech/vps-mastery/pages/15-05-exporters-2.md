### The metrics worth knowing by name

| Metric | Answers |
|---|---|
| `node_filesystem_avail_bytes` | Disk left |
| `node_memory_MemAvailable_bytes` | Real memory left |
| `node_load1` | Load average |
| `container_memory_usage_bytes` | Per-container memory |
| `container_cpu_usage_seconds_total` | Per-container CPU, as a counter |
| `up` | Whether a scrape target answered |
