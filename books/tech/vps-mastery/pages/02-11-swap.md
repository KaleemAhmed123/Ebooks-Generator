## Swap

- **Swap** is disk space the kernel uses when RAM runs out. It is far slower than RAM and far better than a process being killed
- Most VPS images ship with none:

```bash
free -h
#               total   used   free
# Mem:          3.8Gi  180Mi  3.4Gi
# Swap:            0B     0B     0B
```

### Creating a swap file

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

- Make it survive a reboot by appending to `/etc/fstab`:

```text
/swapfile none swap sw 0 0
```

### How much

- Roughly equal to RAM, capped around 4 GB. Swap exists to absorb a spike, not to run on

### Tuning how eagerly it is used

```bash
sudo sysctl vm.swappiness=10
echo "vm.swappiness=10" | sudo tee /etc/sysctl.d/99-swap.conf
```

- The default of 60 swaps too readily for a server. 10 means "only when close to full"

### The honest limit

- Swap turns an out-of-memory kill into a very slow server. That is an improvement during a build spike and a problem under sustained load
- If swap is in constant use, the box is too small. Page 17-03 covers diagnosing that
