### Storage

```bash
aws ec2 describe-volumes --filters Name=attachment.instance-id,Values=i-0abc
```

- **`gp3` is the default worth using.** Unlike `gp2` its throughput and IOPS are set independently of size, so a small fast disk is possible
- The root volume is deleted with the instance by default. **Nothing important should be on it**

### Choosing an image

- **Amazon Linux 2023** for AWS integration, or **Ubuntu LTS** for familiarity. Both are fine
- Pin the AMI id per region and update it deliberately, so a rebuild does not silently change the operating system
