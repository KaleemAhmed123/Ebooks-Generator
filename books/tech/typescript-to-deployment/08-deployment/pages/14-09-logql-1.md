## LogQL

- A LogQL query is **a stream selector, then filters, then optionally an aggregation**. The selector is mandatory and it is what makes the query fast

```logql
{service="orders-api"}                                   # every line from the service
{service="orders-api", level="error"}                    # narrowed by label
{service=~"orders-.*", env="prod"}                       # regex on a label
```

### Filtering the line

```logql
{service="orders-api"} |= "ECONNREFUSED"                 # contains
{service="orders-api"} != "health"                       # does not contain
{service="orders-api"} |~ "timeout|ETIMEDOUT"            # regex
{service="orders-api"} | json | status >= 500            # parse JSON, then compare
{service="orders-api"} | json | tenantId="t_42" | line_format "{{.msg}}"
```

- **`| json` parses the line into fields**, and then every field is queryable without ever having been indexed. That is the payoff for keeping labels small

### Counting

```logql
sum(rate({service="orders-api", level="error"}[5m]))

sum by (route) (
  rate({service="orders-api"} | json | status >= 500 [5m])
)

topk(10, sum by (tenantId) (count_over_time({service="orders-api"} | json [1h])))
```
