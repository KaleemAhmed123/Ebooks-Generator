## SNS

- SQS is one queue, one set of consumers. **SNS is publish and subscribe: one message, many independent subscribers**
- Publishing an `order.created` event once and having billing, email and analytics each receive it is what SNS is for

```bash
aws sns create-topic --name order-events

aws sns subscribe --topic-arn <topic> --protocol sqs \
  --notification-endpoint arn:aws:sqs:ap-south-1:123456789012:email-queue \
  --attributes '{"RawMessageDelivery":"true"}'

aws sns publish --topic-arn <topic> \
  --message '{"orderId":"o_842","total":50000}' \
  --message-attributes '{"eventType":{"DataType":"String","StringValue":"order.created"}}'
```
