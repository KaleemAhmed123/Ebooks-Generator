# Module 12 - Messaging on AWS

## SQS

- Booklet 5 covered queues with RabbitMQ and BullMQ. **SQS is the managed version: no broker to run, no Redis to size, no failover to plan**
- It is the default for background work on AWS, and it behaves differently enough to be worth learning properly

```bash
aws sqs create-queue --queue-name orders-dlq

aws sqs create-queue --queue-name orders \
  --attributes '{
    "VisibilityTimeout": "300",
    "MessageRetentionPeriod": "1209600",
    "RedrivePolicy": "{\"deadLetterTargetArn\":\"arn:aws:sqs:ap-south-1:123456789012:orders-dlq\",\"maxReceiveCount\":\"5\"}"
  }'
```
