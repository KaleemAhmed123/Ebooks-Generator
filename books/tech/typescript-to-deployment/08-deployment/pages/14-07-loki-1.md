## Loki

- Elasticsearch indexes the full text of every log line, which is powerful and expensive. **Loki indexes only labels and stores the lines compressed**
- That single decision makes it roughly an order of magnitude cheaper to run, and it is why it fits on the same box as the application

```yaml
  loki:
    image: grafana/loki:3
    restart: unless-stopped
    command: -config.file=/etc/loki/config.yml
    volumes:
      - ./monitoring/loki.yml:/etc/loki/config.yml:ro
      - ./data/loki:/loki
    ports: ["127.0.0.1:3100:3100"]
    deploy: { resources: { limits: { memory: 1G } } }
```

```yaml
# monitoring/loki.yml
auth_enabled: false                 # single tenant, private network only
server: { http_listen_port: 3100 }
common:
  path_prefix: /loki
  storage: { filesystem: { chunks_directory: /loki/chunks, rules_directory: /loki/rules } }
  replication_factor: 1
  ring: { kvstore: { store: inmemory } }
schema_config:
  configs:
    - from: 2024-01-01
      store: tsdb
      object_store: filesystem
      schema: v13
      index: { prefix: index_, period: 24h }
limits_config:
  retention_period: 720h            # 30 days
  reject_old_samples: true
  max_query_series: 5000
compactor:
  working_directory: /loki/compactor
  retention_enabled: true
  delete_request_store: filesystem
```
