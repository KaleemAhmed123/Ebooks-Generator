## Collecting the logs with Alloy - continued

loki.process "json" {
  stage.json { expressions = { level = "level", msg = "msg", traceId = "traceId" } }
  stage.labels { values = { level = "" } }          // level becomes a label
  stage.timestamp { source = "time" format = "RFC3339" }
  forward_to = [loki.write.default.receiver]
}

loki.write "default" {
  endpoint { url = "http://loki:3100/loki/api/v1/push" }
}
```

- **`stage.labels` promotes only `level`.** Promoting `traceId` would create one stream per request, which is the mistake from the last page
- **`stage.timestamp` uses the log's own time**, not the time Alloy read it. Without it, a backlog after a restart lands with the wrong timestamps
- The UI on port 12345 shows every component and whether it is healthy, which is where you debug a pipeline that is not delivering
