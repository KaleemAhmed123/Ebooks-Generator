## ECR

- **ECR** is a private container registry inside your account, with IAM as the access control and no separate credentials to manage

```bash
aws ecr create-repository --repository-name orders-api \
  --image-scanning-configuration scanOnPush=true \
  --image-tag-mutability IMMUTABLE

aws ecr get-login-password --region ap-south-1 \
  | docker login --username AWS --password-stdin 123456789012.dkr.ecr.ap-south-1.amazonaws.com

docker tag orders-api:$SHA 123456789012.dkr.ecr.ap-south-1.amazonaws.com/orders-api:$SHA
docker push 123456789012.dkr.ecr.ap-south-1.amazonaws.com/orders-api:$SHA

aws ecr describe-images --repository-name orders-api \
  --query 'sort_by(imageDetails,&imagePushedAt)[-5:].[imageTags[0],imagePushedAt]' --output table
```

### `IMMUTABLE` is the setting that matters

- **A tag cannot be overwritten once pushed.** The image running in production is provably the image that was tested
- Without it, `latest` or even a version tag can be replaced, and "what is actually deployed" becomes unanswerable
