### The configuration worth having

```nginx
ssl_protocols TLSv1.2 TLSv1.3;
ssl_prefer_server_ciphers off;
ssl_session_cache shared:SSL:10m;
ssl_session_timeout 1d;
ssl_stapling on;
ssl_stapling_verify on;

add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Content-Type-Options nosniff always;
add_header X-Frame-Options DENY always;
add_header Referrer-Policy strict-origin-when-cross-origin always;
```

- **`ssl_session_cache` matters.** Without it every request pays a full handshake, and it is a visible latency difference
- **HSTS is hard to undo.** `max-age=31536000` tells browsers to refuse plain HTTP for a year. Test with a short value first
- `always` makes the header apply to error responses too, which is where it is usually missing

### Checking it

```bash
openssl s_client -connect api.example.com:443 -servername api.example.com </dev/null | head -20
curl -sI https://api.example.com | grep -i strict-transport
echo | openssl s_client -connect api.example.com:443 2>/dev/null | openssl x509 -noout -dates
```
