## Caddy - continued

- **`X-Forwarded-For`, `X-Forwarded-Proto` and `Host` are set correctly by default.** Module 5's proxy header page exists because Nginx does not do this
- HTTP/3 is on by default once port 443 UDP is published
- **The config file is roughly a fifth the size** of the equivalent Nginx

```bash
caddy validate --config /etc/caddy/Caddyfile
caddy reload --config /etc/caddy/Caddyfile      # zero downtime
caddy fmt --overwrite /etc/caddy/Caddyfile
```

- **The trade is throughput at the very top end and a smaller body of documented recipes.** For most services neither matters
