# Module 10 - Data and state

## RDS

- **RDS is a managed database.** AWS runs the host, the patching, the backups and the failover. You run the schema and the queries
- Running Postgres on an EC2 instance yourself saves money and costs you backups, upgrades, replication and a pager. It is almost never worth it

```bash
aws rds create-db-instance \
  --db-instance-identifier orders-prod \
  --engine postgres --engine-version 18.1 \
  --db-instance-class db.m7g.large \
  --allocated-storage 100 --max-allocated-storage 500 --storage-type gp3 \
  --master-username app --manage-master-user-password \
  --db-subnet-group-name private-data --vpc-security-group-ids sg-database \
  --multi-az \
  --backup-retention-period 14 \
  --storage-encrypted \
  --enable-performance-insights \
  --deletion-protection \
  --no-publicly-accessible
```

| Flag | Why |
|---|---|
| `--manage-master-user-password` | AWS creates and rotates it in Secrets Manager. **No password in your terminal history** |
| `--max-allocated-storage` | storage autoscaling, so a full disk is not an outage |
| `--storage-encrypted` | at rest. **Cannot be enabled later without a snapshot restore** |
| `--deletion-protection` | the flag that saves an account |
| `--no-publicly-accessible` | the database has no public address, ever |
