### Alias records

- An **alias** is a Route 53 record that points at an AWS resource by name and resolves to its current addresses
- **A `CNAME` cannot exist at the zone apex**, so `example.com` cannot be a `CNAME` to a load balancer. An alias can
- Alias queries to AWS targets are free, where ordinary queries are billed

| Record | Holds |
|---|---|
| `A` / `AAAA` | an address, or an alias to an AWS resource |
| `CNAME` | another name. Never at the apex |
| `MX` | mail servers |
| `TXT` | verification, SPF, DKIM |
| `NS` | which nameservers are authoritative |

### TTL, and the deploy trap

- **Lower the TTL to 60 seconds a day before a planned migration.** A record cached for an hour is a change that takes an hour to take effect
- Routing policies: **failover** for an active and standby pair, **latency** to send users to the nearest region, **weighted** for a gradual regional shift

```bash
dig +short api.example.com
dig api.example.com NS +short
```
