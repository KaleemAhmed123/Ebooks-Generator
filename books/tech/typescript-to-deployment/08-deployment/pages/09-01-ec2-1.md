# Module 9 - Compute

## EC2

- An **EC2 instance** is a virtual machine. You choose the size, the operating system image, and the disk, and you are responsible for everything on it
- It is the most work and the most control, and it is still where a large share of production runs

### Instance families

| Family | Balance | Fits |
|---|---|---|
| `t4g`, `t3` | burstable, cheap | development, low steady traffic |
| `m7g`, `m7i` | general purpose | **most API servers** |
| `c7g` | compute heavy | encoding, image processing |
| `r7g` | memory heavy | caches, in-memory work |

- **A `g` suffix means Graviton**, the ARM processor. Roughly 20 percent cheaper for the same performance, and Node runs on it without change
- **Build a multi-architecture image** if you use Graviton, or the container will not start

### The burstable trap

- `t` instances earn CPU credits while idle and spend them under load. **When credits run out, the instance is throttled to a fraction of a core**
- The symptom is a service that is fast for two weeks and then inexplicably slow, with no code change
- Watch `CPUCreditBalance`. If it trends to zero, the instance family is wrong
