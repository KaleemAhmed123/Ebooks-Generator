## TLS

- **TLS is not optional.** Browsers mark plain HTTP as insecure, cookies cannot be `Secure`, and HTTP/2 requires it in practice
- On an instance, Let's Encrypt issues free certificates and renews them automatically. On AWS, ACM does it and the ALB terminates instead

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d api.example.com -d www.api.example.com
sudo certbot renew --dry-run           # prove renewal works before it matters
systemctl list-timers | grep certbot   # the renewal timer
```

- Certbot edits the Nginx config, obtains the certificate, and installs a systemd timer that renews at 60 days
