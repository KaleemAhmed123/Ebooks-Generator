## CDK and CloudFormation - continued

```bash
cdk bootstrap                 # once per account and region
cdk synth                     # print the generated CloudFormation
cdk diff                      # what would change
cdk deploy OrdersStack
cdk destroy OrdersStack
```

### The trade against Terraform

- **CDK is faster to write and harder to predict.** A one line change to a construct can replace a resource, and `cdk diff` is the only warning
- **CloudFormation stack updates can fail halfway and roll back slowly**, which Terraform does not do
- **Terraform's `plan` is more explicit**, which is why it remains the recommendation for infrastructure a team shares
- **Use whichever the team will actually maintain.** Both beat clicking in the console by an enormous margin
