### Memory

- **Set `maxmemory` below the container limit.** Redis needs headroom for the copy-on-write fork during a save
- A rule of thumb: `maxmemory` at about 70 percent of the container limit

```bash
docker compose exec redis redis-cli -a "$REDIS_PASSWORD" info memory | head -20
docker compose exec redis redis-cli -a "$REDIS_PASSWORD" info persistence | grep -E 'aof_|rdb_last'
docker compose exec redis redis-cli -a "$REDIS_PASSWORD" --bigkeys
```
