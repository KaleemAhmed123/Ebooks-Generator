## Caddy

- Module 3 used Caddy for TLS in five lines. **This is what it does beyond that**, because on a small deployment it often replaces Nginx entirely
- Its distinguishing feature is that **HTTPS is automatic and on by default**: certificates are obtained, renewed and stapled with no configuration and no cron job

```text
api.example.com {
	reverse_proxy api:3000 {
		health_uri      /health
		health_interval 10s
		fail_duration   30s
		lb_policy       least_conn
	}

	encode zstd gzip

	@static path /assets/*
	header @static Cache-Control "public, max-age=31536000, immutable"

	@stream path /api/v1/stream*
	reverse_proxy @stream api:3000 {
		flush_interval -1
	}

	rate_limit {
		zone api { key {remote_host} events 100 window 1m }
	}

	log { output file /var/log/caddy/access.log { roll_size 20mb roll_keep 5 } format json }
}
```
