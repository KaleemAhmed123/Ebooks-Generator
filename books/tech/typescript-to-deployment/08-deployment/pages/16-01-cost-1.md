# Module 16 - Cost, security and the release

## Knowing what it costs

- An AWS bill is a surprise by default. **Nothing warns you** until the invoice arrives, unless you set it up

```bash
aws budgets create-budget --account-id 123456789012 --budget '{
  "BudgetName": "monthly",
  "BudgetLimit": { "Amount": "2000", "Unit": "USD" },
  "TimeUnit": "MONTHLY",
  "BudgetType": "COST"
}' --notifications-with-subscribers file://notifications.json

aws ce get-cost-and-usage \
  --time-period Start=2026-08-01,End=2026-09-01 \
  --granularity MONTHLY --metrics UnblendedCost \
  --group-by Type=DIMENSION,Key=SERVICE \
  --query 'ResultsByTime[0].Groups[].[Keys[0],Metrics.UnblendedCost.Amount]' --output table
```

### Set an alert at 50, 80 and 100 percent of forecast

- **The forecast alert is the useful one.** It fires early in the month, when the spend can still be changed

### The five lines that are usually larger than expected

| Line | Usually |
|---|---|
| **NAT gateway data** | a service pulling images or writing to S3 through it |
| **CloudWatch Logs** | no retention policy, kept forever |
| **cross-AZ data transfer** | chatty services split across zones |
| **idle resources** | a load balancer, an EBS volume or an Elastic IP nobody removed |
| **over-provisioned RDS** | sized for a launch that never came |
