## Collecting the logs with Alloy

- **Alloy is Grafana's collector**, and it replaces Promtail, which is now deprecated. It reads container logs, adds labels and pushes to Loki
- It also scrapes Prometheus metrics and forwards OpenTelemetry traces, so one agent covers all three signals

```yaml
  alloy:
    image: grafana/alloy:latest
    restart: unless-stopped
    command:
      - run
      - --server.http.listen-addr=0.0.0.0:12345
      - /etc/alloy/config.alloy
    volumes:
      - ./monitoring/config.alloy:/etc/alloy/config.alloy:ro
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - /var/lib/docker/containers:/var/lib/docker/containers:ro
    ports: ["127.0.0.1:12345:12345"]
```

```text

  host = "unix:///var/run/docker.sock"
