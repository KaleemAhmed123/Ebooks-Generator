# Module 1 - Getting started on the server

## What is TypeScript

- TypeScript is JavaScript with a type system added on top
- Created at Microsoft by Anders Hejlsberg, the same person behind Turbo Pascal and C#
- It is a **superset** of JavaScript
  - every valid `.js` file is already a valid `.ts` file
- The types exist only while you write and build
- What actually ships to Node is plain JavaScript

### Why a backend developer cares

- A wrong shape in a request body is caught before it reaches the database
- Renaming a field across twelve services stops being search-and-hope
- The editor knows what a function returns, so you stop opening the function to find out
