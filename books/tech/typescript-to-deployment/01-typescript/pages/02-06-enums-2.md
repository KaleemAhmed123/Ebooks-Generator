### The replacement

```ts
const Status = {
  Open: "open",
  Closed: "closed",
} as const

type Status = typeof Status[keyof typeof Status]   // "open" | "closed"
```

- Same ergonomics, plain JavaScript output, and it type-checks properly
- `as const` and `typeof` are on the next pages

:::note
If you have `erasableSyntaxOnly` switched on, `tsc` will reject `enum` for you. That is the flag doing its job, not a bug.
:::
