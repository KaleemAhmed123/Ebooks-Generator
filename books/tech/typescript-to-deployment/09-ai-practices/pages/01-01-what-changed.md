# Module 1 - The shift

## What actually changed

- Autocomplete has existed for decades. What changed is that a tool can now read a repository, plan a change across several files, run the tests, and open a pull request
- **The unit of delegation moved from a line to a task.** That is the whole shift, and everything in this booklet follows from it
- Booklet 7 was about **building** systems with models. This one is about **working** with them, which is a different skill and a different set of failure modes

### The three things that are now different

- **Writing code is no longer the slow part.** Deciding what to build, and checking what was built, are
- **The bottleneck moved to review.** Teams report far more pull requests and far longer review queues, which is a process problem rather than a tooling one
- **A plausible wrong answer looks exactly like a right one.** Compilers catch syntax; nothing catches confident nonsense except a person who understands the system
