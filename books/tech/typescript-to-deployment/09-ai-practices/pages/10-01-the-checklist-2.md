### Safety

- [ ] Agent permissions tiered: read and local write allowed, side effects ask, destructive denied
- [ ] No production credentials in any agent's environment
- [ ] Public issues and fetched content treated as untrusted input
- [ ] An agent can open a pull request and cannot merge one

### People

- [ ] A named owner per subsystem who reads every change to it
- [ ] Juniors write the important parts by hand, and use it to understand
- [ ] Delivery measured, not generation. Change failure rate watched
- [ ] Someone can explain each subsystem at a whiteboard, today
