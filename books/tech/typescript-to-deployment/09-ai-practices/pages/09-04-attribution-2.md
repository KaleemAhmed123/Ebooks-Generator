### The recommendation

- **A commit trailer, applied consistently, and no change to the review standard**
- **Never let attribution become an excuse.** "The agent wrote it" is not a defence, and a team where it becomes one has a real problem

### Where it is not optional

- **Open source contributions.** Many projects now require disclosure, and some prohibit unreviewed generated contributions. Read the policy before opening a pull request
- **Regulated industries and contracts** that specify provenance. Ask before assuming
