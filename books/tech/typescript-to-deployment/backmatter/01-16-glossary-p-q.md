## Glossary: P to Q

| Term | Means | # |
|---|---|---|
| **PITR** | point-in-time recovery. Restoring a database to any second in the retention window | 8 |
| **PKCE** | the OAuth extension that makes the authorization code flow safe without a secret | 6 |
| **plan mode** | asking an agent for its approach before it edits anything | 9 |
| **presigned URL** | a time-limited link letting a browser talk to object storage directly | 8 |
| **prefetch** | how many unacknowledged messages a consumer will hold at once | 5 |
| **Prisma** | a TypeScript ORM with a generated, fully typed client | 4, 5 |
| **PromQL** | Prometheus's query language. `rate`, aggregation, `histogram_quantile` | 8 |
| **Prometheus** | scrapes a `/metrics` endpoint on each target and stores the samples | 8 |
| **prompt caching** | reusing a processed prompt prefix on the provider side at a tenth of the price | 7 |
| **prompt injection** | hostile text inside data that the model reads as instructions | 7, 9 |
| **protobuf** | the binary format gRPC serializes with, defined by a schema | 6 |
| **provisioned concurrency** | pre-warmed Lambda instances. Removes cold starts and the reason to use Lambda | 8 |
| **query plan** | how the database intends to run a query. `EXPLAIN` shows it | 5 |
