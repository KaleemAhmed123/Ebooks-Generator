## Glossary: L to M

| Term | Means | # |
|---|---|---|
| **LangGraph** | models a process as a graph that can pause, persist and resume | 7 |
| **launch template** | the EC2 configuration an **ASG** creates instances from | 8 |
| **lead time** | how long a change takes from commit to production | 9 |
| **libuv** | the C library giving Node its event loop and thread pool | 3 |
| **lifecycle policy** | a rule expiring or moving objects in S3, or images in a registry | 8 |
| **liveness** | is the process alive at all. Failing it means restart | 8 |
| **LLM as judge** | using a second model to score an output against a rubric | 7, 9 |
| **lockfile** | the exact dependency versions installed. `npm ci` installs it and nothing else | 4, 9 |
| **LogQL** | Loki's query language. A stream selector, then filters, then aggregation | 8 |
| **Loki** | a log store that indexes labels only, not the log text. Far cheaper than the alternative | 8 |
| **long polling** | holding a request open until there is something to answer with | 6 |
| **macrotask** | a callback scheduled for a later event loop turn, such as `setTimeout` | 3 |
| **mapped type** | a type built by walking the keys of another one | 1 |
| **MCP** | Model Context Protocol. One standard interface between an agent and a set of tools | 7, 9 |
| **MCU** | a media server that decodes and re-encodes every stream. Expensive, for weak clients | 6 |
