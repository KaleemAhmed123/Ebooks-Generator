## Glossary: B

| Term | Means | # |
|---|---|---|
| **BFF** | backend for frontend. A gateway shaped for one client rather than for everyone | 6 |
| **bind mount** | a host directory mapped into a container. Used for source in development | 8 |
| **Biome** | a fast formatter and linter in one tool, an alternative to ESLint and Prettier | 4 |
| **blackbox exporter** | probes an endpoint from outside and turns the result into metrics | 8 |
| **bloat** | dead rows a table keeps carrying because **autovacuum** has not reclaimed them | 5 |
| **blue green** | deploying to a second full environment, then switching traffic in one step | 8 |
| **BM25** | the ranking function classic keyword search uses. The other half of **hybrid search** | 7 |
| **branded type** | a nominal type faked in TypeScript so a `UserId` is not assignable to a `string` | 1 |
| **broker** | the process that holds messages between producer and consumer. RabbitMQ, Kafka | 5 |
| **B-tree** | the default index shape. Good for equality, ranges and ordering | 5 |
| **BuildKit** | the Docker build engine. Adds cache mounts, secret mounts and parallel stages | 8 |
| **bulkhead** | isolating resources so one failing dependency cannot exhaust the whole pool | 6 |
