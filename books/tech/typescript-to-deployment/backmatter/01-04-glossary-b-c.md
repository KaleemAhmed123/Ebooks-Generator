## Glossary: B to C

| Term | Means | # |
|---|---|---|
| **BullMQ** | a Redis-backed job queue for Node, with retries, delays and rate limits | 4 |
| **burn rate** | how fast an **error budget** is being spent. What to alert on, not the total | 8 |
| **Caddy** | a reverse proxy that obtains and renews TLS certificates automatically | 8 |
| **cache mount** | a BuildKit mount that keeps a package manager cache between builds, outside the image | 8 |
| **cardinality** | how many distinct values a column or a label has. High cardinality kills a metrics store | 5, 8 |
| **canary** | sending a small share of traffic to a new version and watching before going further | 8 |
| **cgroup** | the Linux feature that caps a container's CPU and memory | 8 |
| **change stream** | MongoDB's feed of changes to a collection. Needs a **replica set** | 5 |
| **characterization test** | a test describing what code does today, not what it should do | 9 |
| **CIDR** | the `10.0.0.0/16` notation for an address range | 8 |
| **circuit breaker** | stops calling a dependency that keeps failing, so failure is fast instead of slow | 6 |
| **claim** | a field inside a **JWT**, such as the subject or the expiry | 6 |
| **CloudFront** | the AWS CDN. Also terminates TLS close to the user | 8 |
| **CloudWatch** | AWS logs, metrics and alarms | 8 |
