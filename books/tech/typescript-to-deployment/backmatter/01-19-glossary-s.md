## Glossary: S

| Term | Means | # |
|---|---|---|
| **serializable** | the strictest isolation level. Behaves as if transactions ran one at a time | 5 |
| **server action** | a Next.js function that runs on the server and is called from the client | 2 |
| **`server-only`** | an import that turns an accidental server-to-client leak into a build error | 2 |
| **SFU** | a media server forwarding streams without re-encoding. How group calls work | 6 |
| **sharding** | splitting data across machines by a key | 5 |
| **SIGTERM** | the signal asking a process to shut down cleanly. Your handler must catch it | 3, 8 |
| **silence** | temporarily muting an alert, for example during a deploy | 8 |
| **SLI, SLO, SLA** | the measurement, the target, and the contract with money attached | 8 |
| **slopsquatting** | registering package names models hallucinate, and waiting for someone to install one | 9 |
| **span** | one timed operation inside a **trace** | 8 |
| **spec-driven development** | writing and agreeing the specification before generating any code | 9 |
| **SSE** | Server-Sent Events. One-way streaming over plain HTTP | 6, 7 |
| **SSM** | AWS Systems Manager. Gives a shell with no open port and no key | 8 |
| **sticky session** | pinning a client to one backend. A sign sessions are in the wrong place | 8 |
