## Glossary: H to I

| Term | Means | # |
|---|---|---|
| **hallucination** | a confident, well-formed, wrong answer. It looks exactly like a correct one | 7 |
| **HATEOAS** | including links to the next actions in a response. Rarely worth it in practice | 6 |
| **healthcheck** | the endpoint an orchestrator asks before sending traffic | 8 |
| **histogram** | a metric of bucketed observations. The only type that yields real percentiles | 8 |
| **HMAC** | a hash mixed with a shared secret, so only the holder can produce a valid one | 3, 6 |
| **HNSW** | the graph index that makes vector search fast. Approximate by design | 7 |
| **HSTS** | a header telling browsers to refuse plain HTTP for this host. Hard to undo | 8 |
| **HyDE** | drafting a fake answer and embedding that, because answers match answers | 7 |
| **hybrid search** | running vector and keyword search together and fusing the results | 7 |
| **hydration** | attaching client JavaScript to server-rendered HTML | 2 |
| **IaC** | infrastructure as code. Terraform, CDK, CloudFormation | 8 |
| **IAM** | the AWS service deciding who may do what to which resource | 8 |
| **ICE** | how two WebRTC peers discover a path to each other | 6 |
| **idempotency key** | a client-generated id so a retried write is not applied twice | 5, 6 |
