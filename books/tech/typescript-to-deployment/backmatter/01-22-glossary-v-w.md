## Glossary: V to W

| Term | Means | # |
|---|---|---|
| **Valkey** | the open source fork of Redis. Protocol identical, drop-in | 8 |
| **vacuum** | reclaiming space from dead rows in Postgres | 5 |
| **variance** | how a generic behaves when its parameter is substituted for a subtype | 1 |
| **vector store** | where **embeddings** live and similarity search happens | 7 |
| **verification tax** | the effort of checking generated code. Where the time saved goes | 9 |
| **visibility timeout** | how long an SQS message is hidden after being received | 5, 8 |
| **VPC** | a private network inside AWS with an address range you choose | 8 |
| **WAF** | a firewall inspecting requests before they reach the service | 8 |
| **WAL** | the write-ahead log. Every change is written there first, which is what makes recovery work | 5 |
| **WebRTC** | peer-to-peer audio, video and data between browsers | 6 |
| **webhook** | an HTTP callback from a third party. Verify the signature over the raw body | 6 |
| **WebSocket** | a persistent two-way connection, upgraded from an HTTP request | 6 |
| **Web Streams** | the standard streaming API, shared with browsers and edge runtimes | 3 |
| **WiredTiger** | MongoDB's storage engine. Takes half the available RAM unless capped | 5, 8 |
| **worker thread** | a real Node thread for CPU-bound work, so the event loop stays free | 3 |
