## Glossary: D to E

| Term | Means | # |
|---|---|---|
| **DORA** | the four delivery metrics: deploy frequency, lead time, change failure rate, restore time | 9 |
| **draining** | letting existing requests finish on a target that is being removed | 8 |
| **drift** | infrastructure changed by hand no longer matching what the code declares | 8 |
| **DTO** | data transfer object. The explicit shape crossing a boundary, not the database row | 1, 4 |
| **dual write** | writing to two systems without a transaction. One will eventually fail | 5 |
| **duplex** | a stream that is both readable and writable. A TCP socket is one | 3 |
| **EBS** | the network attached disk an EC2 instance uses | 8 |
| **EC2** | an AWS virtual machine | 8 |
| **ECR** | the private container registry inside an AWS account | 8 |
| **ECS** | the AWS container orchestrator. **Fargate** is the mode with no machines to manage | 8 |
| **edge runtime** | a restricted JavaScript runtime that runs close to users. No `fs`, no TCP | 2 |
| **ElastiCache** | managed Redis or Valkey on AWS | 8 |
| **embedding** | a list of numbers representing meaning, so similar text lands close together | 7 |
