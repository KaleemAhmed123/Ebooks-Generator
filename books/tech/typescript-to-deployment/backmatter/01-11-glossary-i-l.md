## Glossary: I to L

| Term | Means | # |
|---|---|---|
| **idempotent** | applying it twice has the same effect as applying it once | 5, 6 |
| **IMDSv2** | the token-based instance metadata service. The v1 form made SSRF into stolen credentials | 8 |
| **index** | a structure letting a database find rows without reading the table | 5 |
| **infer** | the keyword that captures a type inside a **conditional type** | 1 |
| **inhibition** | suppressing an alert while a more serious related one is firing | 8 |
| **instrumentation.ts** | the Next.js hook that runs before anything else, for tracing setup | 2 |
| **interrupt** | pausing a LangGraph run so a person can decide, then resuming it | 7 |
| **ISR** | rendering a page on first request, then serving it from cache | 2 |
| **isolation level** | how much one transaction sees of another's uncommitted work | 5 |
| **IVFFlat** | a vector index that clusters first. Cheaper to build than **HNSW**, less accurate | 7 |
| **jitter** | randomness added to a retry delay so clients do not all retry together | 6 |
| **JWT** | a signed token carrying **claims**. Readable by anyone, changeable by nobody | 6 |
| **Kafka** | an append-only log consumers read at their own position. Replay is normal | 5 |
| **keyof** | the union of a type's property names | 1 |
| **LangChain** | a framework for model-agnostic agents. Version 1 is `createAgent` plus middleware | 7 |
