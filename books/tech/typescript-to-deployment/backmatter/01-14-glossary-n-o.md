## Glossary: N to O

| Term | Means | # |
|---|---|---|
| **N+1** | one query for a list, then one more per row. The most common slow endpoint | 5, 6 |
| **NACL** | a stateless subnet firewall. Security groups are the ones to reach for | 8 |
| **namespace** | the Linux feature that limits what a container can see | 8 |
| **NAT gateway** | outbound internet for private subnets. Nothing can start a connection inward | 8 |
| **`never`** | the type with no values. Reaching it is how exhaustiveness is proved | 1 |
| **nack** | a consumer telling the broker it could not handle a message | 5 |
| **non-repeatable read** | reading the same row twice in one transaction and getting two answers | 5 |
| **`noUncheckedIndexedAccess`** | the strict flag that admits an array lookup might be undefined | 1, 9 |
| **object mode** | a Node stream carrying JavaScript values rather than bytes | 3 |
| **OIDC** | an identity layer over OAuth. Also how CI proves who it is to AWS without a key | 6, 8 |
| **offset** | a consumer's position in a Kafka partition. Moving it back is replay | 5 |
| **offset pagination** | paging with `LIMIT` and `OFFSET`. Simple, and it drifts and gets slower | 6 |
| **OpenAPI** | a machine-readable description of an HTTP API | 6 |
