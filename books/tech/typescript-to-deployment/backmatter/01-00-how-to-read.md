# Glossary

## How to read it

- Around 350 terms, alphabetical. Every one of them appears somewhere in the nine booklets
- The number in the last column is the booklet that explains it properly. Go there when one line is not enough

| # | Booklet |
|---|---|
| 1 | TypeScript for Backend |
| 2 | Next.js, The Backend Half |
| 3 | Node.js Core |
| 4 | The Node Ecosystem |
| 5 | Data & Messaging |
| 6 | API & Service Design |
| 7 | AI SDKs for Backend |
| 8 | Deployment & Ops on AWS |
| 9 | AI-Assisted Engineering |

- A term with two numbers is covered from two angles. Socket.IO is a library in Booklet 4 and a design decision in Booklet 6
- **Bold** inside a definition means that word is its own entry
