## Glossary: T to U

| Term | Means | # |
|---|---|---|
| **tmpfs** | a memory-only mount. Nothing touches disk | 8 |
| **token** | the unit a model reads and is billed by. Roughly four characters of English | 7 |
| **tool calling** | the model naming a function and its arguments, for your code to run | 7 |
| **ToolLoopAgent** | the AI SDK class bundling a model, tools and a stopping condition | 7 |
| **trace** | one request as a tree of timed **spans** across every service it touched | 8 |
| **transaction** | a group of writes that all succeed or all roll back | 5 |
| **transform stream** | a stream that reads, changes and writes | 3 |
| **tree shaking** | dropping code nothing imports at build time | 4 |
| **tRPC** | end-to-end typed RPC for TypeScript, with no schema language | 6 |
| **TTL** | time to live. How long a cache entry, DNS record or document survives | 5 |
| **tuple** | a fixed-length array where each position has its own type | 1 |
| **ufw** | the simple Linux firewall. Docker bypasses it, which is the trap | 8 |
| **`unknown`** | the safe counterpart to `any`. You must narrow before using it | 1 |
| **Uptime Kuma** | self-hosted uptime monitoring, run somewhere other than the thing it watches | 8 |
| **utility type** | a built-in type helper: `Partial`, `Pick`, `Omit`, `Record`, `ReturnType` | 1 |
