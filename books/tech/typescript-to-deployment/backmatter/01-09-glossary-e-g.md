## Glossary: E to G

| Term | Means | # |
|---|---|---|
| **exporter** | a small process turning something else into Prometheus metrics | 8 |
| **fanout** | one message delivered to several independent consumers | 5 |
| **Fargate** | ECS mode where AWS provides the machine, so there is no instance to patch | 8 |
| **feature flag** | a switch separating shipping code from releasing it | 6 |
| **fine-tuning** | training a model further on your own examples to change its default behavior | 7 |
| **GIN** | a Postgres index for values that contain many items: arrays, JSON, full text | 5 |
| **generic** | a type parameter, so one function or type works over many shapes | 1 |
| **generateStaticParams** | tells Next.js which dynamic routes to build ahead of time | 2 |
| **GiST** | a Postgres index for geometric and range types | 5 |
| **graceful shutdown** | stop accepting work, finish what is in flight, then exit | 3, 8 |
| **Grafana** | the interface over metrics, logs and traces | 8 |
| **GraphQL** | a query language where the client asks for exactly the fields it wants | 6 |
| **grounding** | making an answer traceable to text that was actually retrieved | 7 |
| **gRPC** | a binary RPC protocol over HTTP/2, defined by a `.proto` contract | 6 |
| **guardrail** | a check around a model call. Code that can say no, unlike an instruction | 7 |
