## Glossary: S to T

| Term | Means | # |
|---|---|---|
| **streaming** | sending an answer in pieces as it is produced | 7 |
| **structured output** | constraining generation to a JSON schema, so the result is valid by construction | 7 |
| **structural typing** | TypeScript compares shapes, not names | 1 |
| **STUN, TURN** | how WebRTC peers find each other, and relay when they cannot connect directly | 6 |
| **Tailscale** | a private network so admin interfaces are never on the public internet | 8 |
| **target group** | the set of backends an **ALB** sends traffic to, with its own health check | 8 |
| **Tempo** | Grafana's trace store | 8 |
| **template literal type** | a type describing a string pattern, so the compiler generates the members | 1 |
| **Terraform** | declares infrastructure as code, with a `plan` before every `apply` | 8 |
| **thread pool** | libuv's four threads doing file and DNS work off the event loop | 3 |
| **thundering herd** | every client retrying at the same instant after an outage | 6 |
| **TIMESTAMPTZ** | an absolute moment. `TIMESTAMP` is a wall clock reading with no zone | 5 |
| **timingSafeEqual** | comparing secrets in constant time, so timing does not leak the answer | 3 |
