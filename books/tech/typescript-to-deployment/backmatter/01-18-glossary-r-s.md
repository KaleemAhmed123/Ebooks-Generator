## Glossary: R to S

| Term | Means | # |
|---|---|---|
| **RPO** | recovery point objective. How much data you can afford to lose | 8 |
| **RRF** | reciprocal rank fusion. Merging two ranked lists by position, not by score | 7 |
| **RSC** | React Server Component. Renders on the server and ships no JavaScript for itself | 2 |
| **RTO** | recovery time objective. How long you can be down | 8 |
| **runbook** | the steps for one alert, written before the incident, not during it | 8 |
| **S3** | AWS object storage. Keys, not directories | 8 |
| **saga** | a sequence of local transactions with compensating actions, instead of one distributed one | 5 |
| **`satisfies`** | checks a value against a type without widening its inferred type | 1 |
| **scrape** | Prometheus pulling metrics from a target | 8 |
| **security group** | a stateful firewall on a resource. Reference other groups, never address ranges | 8 |
| **selectivity** | what fraction of rows a condition matches. Low selectivity makes an index useless | 5 |
| **semver** | major.minor.patch, where major means a breaking change | 4 |
| **sequential scan** | reading the whole table. Correct on a small one, fatal on a large one | 5 |
