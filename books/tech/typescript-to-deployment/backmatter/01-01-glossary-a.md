## Glossary: A

| Term | Means | # |
|---|---|---|
| **ACID** | atomicity, consistency, isolation, durability. What a **transaction** guarantees | 5 |
| **ack** | a consumer telling the broker a message was handled, so it can be dropped | 5 |
| **ACM** | the AWS service that issues and renews TLS certificates at no cost | 8 |
| **agent** | a loop: call the model, run the tool it asks for, feed the result back, repeat | 7 |
| **AGENTS.md** | a plain Markdown file at a repository root telling coding agents how to build and change it | 9 |
| **ALB** | Application Load Balancer. Terminates TLS and spreads HTTP traffic across healthy targets | 8 |
| **Alertmanager** | decides who is told about a firing alert, groups related ones, and suppresses noise | 8 |
| **Alloy** | Grafana's collector. Reads container logs and metrics and forwards them. Replaces Promtail | 8 |
| **AMI** | the disk image an EC2 instance boots from | 8 |
| **`any`** | the TypeScript escape hatch that turns off checking. Almost always the wrong answer | 1 |
| **AOF** | append-only file. Redis persistence that logs every write, unlike a periodic snapshot | 5 |
| **ARN** | Amazon Resource Name. The unique identifier every AWS resource has | 8 |
