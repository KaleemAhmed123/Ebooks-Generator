## Glossary: O to P

| Term | Means | # |
|---|---|---|
| **OpenTelemetry** | the vendor-neutral standard for traces, metrics and logs | 4, 8 |
| **optimistic locking** | checking a version on write instead of holding a lock | 5 |
| **ORM** | maps database rows to objects. Prisma, Mongoose, TypeORM | 4, 5 |
| **outbox** | writing an event to your own database in the same transaction, then publishing it | 5 |
| **OverlayFS** | the copy-on-write filesystem stacking container image layers | 8 |
| **partial index** | an index over only the rows matching a condition. Smaller and faster | 5 |
| **partition** | a slice of a Kafka topic, and the unit of ordering and parallelism | 5 |
| **partitioning** | splitting one large table into physical pieces by a key | 5 |
| **peer dependency** | a package your library needs the consumer to install, not you | 4 |
| **pessimistic locking** | taking a lock before reading, so nobody else can change the row | 5 |
| **pgvector** | the Postgres extension adding a vector column type and similarity search | 7 |
| **phantom read** | a second query in the same transaction returning rows that were not there | 5 |
| **PID 1** | the first process in a container. It gets no default signal handlers | 3, 8 |
| **pino** | a fast JSON logger for Node. Faster than the alternatives because it serializes directly | 4, 8 |
