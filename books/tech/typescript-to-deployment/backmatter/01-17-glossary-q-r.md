## Glossary: Q to R

| Term | Means | # |
|---|---|---|
| **quorum queue** | a RabbitMQ queue replicated across nodes. The modern default, needs three | 5, 8 |
| **RabbitMQ** | a broker built for routing, per-message acknowledgement and dead letter queues | 5 |
| **RAG** | retrieval-augmented generation. Find the relevant passages, then answer over them | 7 |
| **rate limit** | a cap on how many requests a caller may make in a window | 6 |
| **readiness** | can the process serve a request right now. Failing it means stop sending traffic | 8 |
| **read replica** | an asynchronous copy of a database serving reads. It lags | 5, 8 |
| **recording rule** | a Prometheus query computed on a schedule and stored as a new series | 8 |
| **Redis** | an in-memory store used for caching, sessions, queues and rate limiting | 5 |
| **reranker** | a slower model scoring query and document together. Far more accurate than embeddings | 7 |
| **replica set** | a MongoDB cluster. Required for transactions and change streams, even with one node | 5, 8 |
| **replication lag** | how far behind a replica is. Reading your own write from one is a bug | 5 |
| **REST** | a convention over HTTP: resources, methods, status codes | 6 |
| **revalidateTag** | invalidating a Next.js cache entry by tag | 2 |
