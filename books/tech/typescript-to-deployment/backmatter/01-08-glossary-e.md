## Glossary: E

| Term | Means | # |
|---|---|---|
| **enum** | a named set of constants. In TypeScript a `const` object is often the better choice | 1 |
| **ephemeral cache** | Anthropic's prompt cache marker. Five minutes by default | 7 |
| **error budget** | how much failure an **SLO** allows before feature work stops | 8 |
| **ESM** | ECMAScript modules, the `import` form. The standard, and not the same as **CommonJS** | 1, 3 |
| **ETag** | a version marker for a response, used for conditional requests and optimistic locking | 6 |
| **eval** | a fixed set of inputs and scorers, run to measure a non-deterministic system | 7, 9 |
| **event loop** | the single thread that runs your JavaScript. Blocking it stops everything | 3 |
| **EventBridge** | AWS routing by the content of an event, plus schedules | 8 |
| **eventual consistency** | two systems that agree, but not immediately | 5 |
| **exactly-once** | delivery that neither loses nor repeats. Achieved with **idempotency**, not by the broker | 5 |
| **exemplar** | a trace id attached to a metric sample, so a spike links to the request that caused it | 8 |
| **exhaustiveness check** | assigning to `never` so the compiler fails when a union gains a member | 1 |
| **expand and contract** | adding the new schema, migrating, then removing the old one, in separate deploys | 5, 8 |
