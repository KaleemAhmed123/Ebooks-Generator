## Evaluations

- Ordinary code is tested by asserting on output. Model output changes between runs, so equality assertions are useless
- **An evaluation is a test suite for a non-deterministic function**: a fixed set of inputs, a scorer per input, and a pass threshold over the set
- Without one, every prompt change is a guess, and a regression is discovered by a customer

```ts
// eval/triage.json
[
  { "input": "my card was charged twice", "expect": { "category": "billing" } },
  { "input": "the app crashes on checkout", "expect": { "category": "technical" } }
]
```

```ts
const results = await Promise.all(cases.map(async (c) => {
  const { object } = await generateObject({ model, schema: Ticket, prompt: c.input })
  return object.category === c.expect.category
}))

const passRate = results.filter(Boolean).length / results.length
expect(passRate).toBeGreaterThan(0.9)
```
