### The three kinds of scorer

| Scorer | Use for |
|---|---|
| **exact or schema** | classification, extraction, routing |
| **similarity** | summaries, paraphrases |
| **model as judge** | tone, helpfulness, faithfulness |

- **A judge needs a rubric and a scale**, not "is this good". Vague criteria give noise

### Making it a habit

- **Start with twenty cases.** A small set run on every change beats a large one built later and never run
- **Every production failure becomes a case**, permanently. That is how the set stops being synthetic
- Run it in CI on any change to a prompt, a model, a chunking rule or a tool. Those are exactly the changes that silently move quality
