# Module 1 - Getting started

## What is Next.js

- Next.js is a React framework that runs on a Node server
- Created by Vercel, first released in 2016
- React on its own only renders. Next.js adds routing, a server, and a build

### The part this booklet is about

- Next.js is usually taught as a frontend framework
- Half of it is a backend, and that half is what a backend developer is hired to work on
- This booklet covers only that half

### What counts as the backend

- **Route Handlers** - your HTTP API, one file per route
- **Server Components** - components that run on the server and can query a database directly
- **Server Actions** - functions that run on the server, called from the client
- **Proxy** - code that runs before a request reaches a route
- **Caching** - four separate layers, each with its own rules
