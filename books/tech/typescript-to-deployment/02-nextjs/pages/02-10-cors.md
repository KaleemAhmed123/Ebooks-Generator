## CORS

- **CORS** is Cross-Origin Resource Sharing, the browser rule that stops a page on one origin from reading a response from another
- It is enforced by the browser, not by your server. `curl` ignores it entirely

### On one route

```ts
export async function GET() {
  return new Response("ok", {
    headers: {
      "Access-Control-Allow-Origin": "https://app.example.com",
      "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type, Authorization",
    },
  })
}
```

### For every route

- Put the headers in `next.config.ts` or in `proxy.ts` instead of repeating them

### The two things people get wrong

- `Access-Control-Allow-Origin: *` and `credentials: "include"` cannot be used together. The browser refuses
- A preflight is a real request. If the browser sends `OPTIONS` and gets a 405, nothing else will work
