## IIFE

- **IIFE** is an Immediately Invoked Function Expression
- A function that is defined and called in one go

```js
;(function () {
  console.log("runs once")
})()

;(() => {
  console.log("arrow version")
})()
```

- The wrapping parentheses turn the declaration into an expression
- The trailing `()` calls it

### What it was for

- Before modules, every script shared one global scope
- An IIFE gave a file its own scope so its variables did not collide

```js
var App = (function () {
  const secret = "hidden"

  return {
    reveal: () => secret,
  }
})()

App.reveal()   // "hidden"
App.secret     // undefined
```

- That pattern has a name, the **module pattern**, and it is a closure

### Do you still need it

- Not for scope. ESM and CommonJS both give every file its own scope
- Still useful for one thing: running an `async` block at the top of a CommonJS file
