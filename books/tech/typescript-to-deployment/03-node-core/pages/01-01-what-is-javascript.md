# Module 1 - JavaScript foundations

## Who created JavaScript

- Written by Brendan Eich at Netscape in 1995, in about ten days
- Named JavaScript for marketing reasons. It has no relationship to Java
- Standardized as **ECMAScript**, which is why versions are called ES2015, ES2020 and so on

### Why this module exists

- Node is JavaScript. Everything below runs on the server exactly as it does in a browser
- Closures, `this`, prototypes and hoisting are still the most asked questions in a Node interview
- TypeScript does not teach any of them, because they are runtime behavior and TypeScript disappears before runtime

### What JavaScript is

- Single threaded. One thing runs at a time
- Dynamically typed. A variable holds any type and can change
- Prototype based, not class based, even though it has a `class` keyword
- Functions are values. They can be passed, returned and stored
