# Module 1 - Choosing dependencies

## How this booklet works

- Two depths, and every entry starts from zero

**Deep entries** get several pages: what it is, install, the smallest working example, the real patterns, and the traps

**One-page entries** get four things
- what it is, in one line
- when to reach for it
- the smallest example
- the gotcha nobody mentions

### Versions

- Every version here was checked on 30 August 2026
- npm moves. Run `npm view <name> version` before trusting a number in any book

### The order

- Grouped by the job you are doing, not alphabetically
- Servers, validation, data, background work, auth, files, realtime, observability, testing, tooling
