### The five patterns you will actually use

```ts
// cache aside
const cached = await redis.get(key)
if (cached) return JSON.parse(cached)
const fresh = await db.orders.findMany()
await redis.set(key, JSON.stringify(fresh), "EX", 60)

// counter with expiry, for rate limiting
const hits = await redis.incr(`rl:${ip}`)
if (hits === 1) await redis.expire(`rl:${ip}`, 60)

// distributed lock
const ok = await redis.set(lockKey, token, "NX", "PX", 5000)

// sorted set as a leaderboard or a delayed queue
await redis.zadd("payouts:due", Date.now() + 86400000, payoutId)

// pub sub, needs a second connection to subscribe
await redis.publish("orders", JSON.stringify({ id: "o1" }))
```

- A subscribing client cannot run normal commands. Create a second connection with `redis.duplicate()`
