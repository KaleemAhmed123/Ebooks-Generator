## jose - continued

const token = await new SignJWT({ role: "seller" })
  .setProtectedHeader({ alg: "HS256" })
  .setSubject(sellerId)
  .setIssuedAt()
  .setIssuer("orders-api")
  .setAudience("storefront")
  .setExpirationTime("15m")
  .sign(secret)
```

```ts
const { payload } = await jwtVerify(token, secret, {
  issuer: "orders-api",
  audience: "storefront",
})
```

- Passing `issuer` and `audience` to `jwtVerify` is what makes them checks rather than decoration
- A token signed for a different service will otherwise verify perfectly well here

### Verifying against a provider

```ts
import { createRemoteJWKSet, jwtVerify } from "jose"

const jwks = createRemoteJWKSet(new URL("https://accounts.google.com/.well-known/jwks.json"))
const { payload } = await jwtVerify(idToken, jwks, { issuer, audience })
```

- The key set is fetched and cached, and key rotation is handled for you
- This is the piece `jsonwebtoken` has no answer for
