### Typed routes end to end

```ts
import { zValidator } from "@hono/zod-validator"

app.post("/orders", zValidator("json", OrderSchema), (c) => {
  const order = c.req.valid("json")   // fully typed
  return c.json(order)
})
```

- `hono/client` can then generate a typed client from the app's type, so the caller gets checked too

### When to pick it

- Anything that must also run on an edge runtime
- A small internal service where startup time matters
- A team that wants Express-shaped code with types that actually work

### When not to

- A large existing Express codebase. The ecosystem of Express middleware is far bigger
