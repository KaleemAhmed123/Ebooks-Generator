### Parsing

```ts
Order.parse(input)       // returns the value, throws ZodError on failure
Order.safeParse(input)   // returns { success, data } or { success, error }
```

```ts
const parsed = Order.safeParse(req.body)
if (!parsed.success) {
  return res.status(400).json({ issues: parsed.error.issues })
}
const order = parsed.data
```

- `parse` at boot, where throwing is what you want
- `safeParse` on request input, where you owe the caller a 400
