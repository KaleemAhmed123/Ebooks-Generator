## Hono

- Express predates the Web standard `Request` and `Response` objects, so it uses Node's own `req` and `res`
- That ties it to Node. The same code cannot run on Cloudflare Workers, Deno, Bun or an edge runtime
- Hono is written against the Web standard objects instead, so one file runs on all of them unchanged
- It is also small, a few kilobytes, which matters where cold start time is billed by the millisecond
- Its routing is typed from the path string itself, so a handler knows its own parameters without you declaring them
- The trade is a much smaller ecosystem. The fifteen years of Express middleware does not work here
- Created by Yusuke Wada, first released in 2022. Hono is Japanese for flame
- Version 4.13.5

```bash
npm i hono @hono/node-server
```

```ts
import { Hono } from "hono"
import { serve } from "@hono/node-server"

const app = new Hono()

app.get("/orders/:id", (c) => c.json({ id: c.req.param("id") }))

serve({ fetch: app.fetch, port: 3000 })
```

- Built on Web standard `Request` and `Response`
- The same file runs on Node, Bun, Deno, Cloudflare Workers and Vercel Edge
