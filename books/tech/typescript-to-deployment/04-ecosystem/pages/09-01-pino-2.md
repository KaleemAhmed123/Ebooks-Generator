## pino - continued

```json
{"level":"info","time":1756512000000,"orderId":"o1","sellerId":"s1","msg":"order created"}
```

- **The object comes first, the message second.** Reversing them puts your data in the message string where nothing can query it
- `redact` is not cosmetic. Logging an `authorization` header puts a live token in your log store forever

### Structured beats formatted

```ts
logger.info(`order ${orderId} created for ${sellerId}`)   // unsearchable
logger.info({ orderId, sellerId }, "order created")       // queryable
```

- Loki, CloudWatch and Elasticsearch can filter on `orderId` only if it is a field
- A message string means grep, and grep across ten instances is not a workflow
