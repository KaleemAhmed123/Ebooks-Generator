## Kafka

- RabbitMQ delivers a message and forgets it. Once acknowledged, it is gone, and a consumer added tomorrow never sees yesterday
- **Kafka** keeps every message in an append-only **log**, retained for days or forever, and consumers track their own position in it
- That single difference changes what it is for. A new consumer can start from the beginning and rebuild its state from history
- Replaying is normal rather than exceptional, which is what makes it the backbone of event sourcing and analytics pipelines

```bash
npm i kafkajs
```

```ts
import { Kafka } from "kafkajs"

const kafka = new Kafka({ clientId: "orders", brokers: [process.env.KAFKA_BROKERS] })

const producer = kafka.producer()
await producer.send({
  topic: "orders",
  messages: [{ key: sellerId, value: JSON.stringify(event) }],
})

const consumer = kafka.consumer({ groupId: "email-service" })
await consumer.subscribe({ topic: "orders", fromBeginning: false })
await consumer.run({
  eachMessage: async ({ message }) => handle(JSON.parse(message.value.toString())),
})
```
